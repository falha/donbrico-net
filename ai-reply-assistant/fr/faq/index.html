Assistant IA — Foire aux questions

Pour commencer

Comment installer l’extension Assistant IA ?

Rendez-vous sur le Chrome Web Store, recherchez « Donbrico AI Reply Assistant » et cliquez sur « Ajouter à Chrome ». Une fois installée, épinglez l’extension à votre barre d’outils pour un accès rapide. Un petit écran de bienvenue vous guidera pour la configuration initiale.

Faut-il un compte pour utiliser l’Assistant IA ?

Oui, vous devez créer un compte Donbrico gratuit pour activer l’extension. Inscrivez-vous directement depuis l’écran d’accueil dans la fenêtre contextuelle de l’extension. Cela vous permet de sauvegarder vos préférences de ton et de gérer votre clé API si vous souhaitez utiliser votre propre modèle.

Que faire juste après l’installation ?

Ouvrez n’importe quelle plateforme de messagerie comme Gmail, une interface de tickets d’assistance ou les messages Airbnb. Cliquez sur l’icône Donbrico dans le champ de saisie – l’extension lira automatiquement le contexte de la conversation. Essayez de générer une réponse avec le ton par défaut pour voir comment ça fonctionne avant de personnaliser les réglages.

Puis-je utiliser cette extension ailleurs que sur les e-mails ?

Absolument. L’Assistant IA fonctionne sur tous les champs de saisie de texte dans votre navigateur – commentaires sur les réseaux sociaux, messages Slack, tickets Zendesk et boîtes de réception Airbnb. Pas besoin de changer d’onglet ni de copier-coller : il détecte la conversation où que vous tapiez.

Fonctionnalités et utilisation

Comment l’extension lit-elle le contexte de ma conversation ?

L’extension analyse le texte visible sur la page, y compris les messages précédents dans le fil de discussion. Elle ne scanne pas tout votre historique de navigation ni les onglets sans rapport. Cette lecture contextuelle permet à l’IA de générer des réponses qui reprennent des points précis de la conversation.

Puis-je modifier le ton des réponses générées ?

Oui. Ouvrez la fenêtre de l’extension et accédez à « Ton et style ». Vous pouvez choisir des options prédéfinies comme Professionnel, Amical ou Concis, ou rédiger une instruction personnalisée telle que « Sonne comme un hôte Airbnb serviable ». L’IA appliquera ce ton à toutes les réponses jusqu’à ce que vous le changiez.

Comment modifier une réponse avant de l’envoyer ?

Après avoir cliqué sur « Générer une réponse », le texte suggéré apparaît directement dans le champ de saisie. Vous pouvez le modifier comme n’importe quel message – ajouter une phrase, changer un mot ou supprimer des parties. L’extension n’envoie rien automatiquement : vous gardez le contrôle total avant d’appuyer sur Envoyer.

Puis-je utiliser l’Assistant IA pour les commentaires sur les réseaux sociaux ?

Oui. Rendez-vous sur n’importe quelle plateforme sociale comme LinkedIn, Twitter ou Facebook. Cliquez dans la zone de commentaire et l’icône Donbrico apparaîtra. L’extension lit le message d’origine et les commentaires existants pour rédiger une réponse pertinente et naturelle.

Fonctionne-t-il avec plusieurs langues ?

L’Assistant IA donne les meilleurs résultats en anglais, mais peut générer des réponses dans d’autres langues si le contexte de la conversation est dans cette langue. Pour de meilleurs résultats, définissez votre langue préférée dans les réglages de ton. Le modèle sous-jacent pourrait produire des réponses moins précises pour les langues peu courantes.

Confidentialité et sécurité

Où sont traitées les données de ma conversation ?

Par défaut, tout le traitement s’effectue localement sur votre appareil via Gemini Nano. Aucun texte de vos conversations n’est envoyé vers des serveurs externes. Si vous choisissez d’utiliser votre propre clé API (BYOK), les données sont envoyées à ce fournisseur (ex : OpenAI) uniquement pour générer la réponse, et Donbrico ne les stocke ni ne les enregistre.

Donbrico stocke-t-il mes messages ou réponses ?

Non. Donbrico ne conserve ni l’historique de vos conversations, ni les réponses générées, ni aucune donnée personnelle sur ses serveurs. L’extension ne garde que vos préférences de ton et les réglages de clé API localement dans votre navigateur. Votre confidentialité est intégrée à la conception – nous n’entraînons pas nos modèles sur vos données.

Que se passe-t-il si j’utilise une clé API gratuite d’un tiers ?

Si vous activez BYOK avec un fournisseur tiers comme OpenAI, le contexte de votre conversation est envoyé aux serveurs de ce fournisseur pour générer la réponse. Consultez la politique de confidentialité de ce fournisseur pour savoir comment il traite les données. Vous pouvez à tout moment revenir à l’IA locale (Gemini Nano) dans les paramètres.

L’extension est-elle sûre pour une utilisation professionnelle ?

Oui. L’extension n’accède pas à vos identifiants de connexion, mots de passe ou informations de paiement. Elle lit uniquement le texte visible dans le champ de saisie actif. De nombreux agents d’assistance et freelances l’utilisent sur des plateformes professionnelles comme Gmail et Zendesk sans aucun problème de sécurité.

Tarifs et licence

Existe-t-il une version gratuite de l’Assistant IA ?

Oui. La version gratuite inclut un nombre illimité de réponses IA locales avec Gemini Nano et des réglages de ton de base. Vous pouvez générer autant de réponses que vous le souhaitez sans payer. Les fonctionnalités premium comme les instructions de ton personnalisées et le support BYOK nécessitent un abonnement.

Qu’apporte un abonnement premium ?

L’abonnement premium débloque la possibilité d’utiliser votre propre clé API (BYOK) pour des modèles de meilleure qualité comme GPT-4, ainsi qu’une personnalisation avancée du ton avec des instructions de style détaillées. Le tarif est mensuel et gérable depuis votre tableau de bord Donbrico.

Puis-je résilier mon abonnement à tout moment ?

Oui. Vous pouvez annuler votre abonnement premium depuis les paramètres de votre compte Donbrico à tout moment. L’accès reste actif jusqu’à la fin de la période de facturation en cours. Après l’annulation, vous revenez au forfait gratuit avec l’IA locale uniquement – aucune donnée n’est perdue.

Dépannage

L’icône de l’extension n’apparaît pas sur ma plateforme de messagerie. Que faire ?

Vérifiez d’abord que l’extension est épinglée à votre barre d’outils. Si elle n’apparaît toujours pas, actualisez la page ou redémarrez Chrome. Sur certaines plateformes (comme certaines applications web personnalisées), il peut être nécessaire de cliquer d’abord dans le champ de texte. Si le problème persiste, assurez-vous que l’extension est activée dans la liste des extensions Chrome.

La réponse générée ne correspond pas au contexte de la conversation. Comment résoudre ce problème ?

Cela arrive généralement lorsque l’extension ne peut pas lire entièrement le fil de discussion. Essayez de faire défiler la page vers le haut pour charger les messages plus anciens à l’écran, puis cliquez à nouveau sur l’icône Donbrico. Vérifiez également que votre réglage de ton n’écrase pas le contexte – réinitialisez-le sur « Neutre » et régénérez.

Ma clé API ne fonctionne pas avec la fonction BYOK. Que dois-je faire ?

Assurez-vous d’avoir copié l’intégralité de la clé API depuis le tableau de bord de votre fournisseur, sans espaces supplémentaires. Vérifiez que la clé dispose d’une facturation active et des autorisations pour le modèle sélectionné. Si le problème persiste, revenez temporairement à l’IA locale et contactez le support avec le message d’erreur affiché dans l’extension.

L’extension ralentit mon navigateur. Existe-t-il une solution ?

Le modèle d’IA local (Gemini Nano) peut utiliser certaines ressources système. Fermez les autres onglets ou extensions lourds pour améliorer les performances. Si vous utilisez un appareil moins puissant, envisagez d’utiliser BYOK avec un modèle cloud, ce qui décharge le traitement vers les serveurs du fournisseur. Vous pouvez également désactiver l’extension sur les pages où vous n’en avez pas besoin.
