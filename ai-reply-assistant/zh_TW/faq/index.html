AI 回覆助手 — 常見問題

開始使用

如何安裝 AI 回覆助手擴充功能？

前往 Chrome 線上應用程式商店，搜尋「Donbrico AI Reply Assistant」，然後點擊「加到 Chrome」。安裝完成後，請將擴充功能釘選到工具列以便快速取用。您會看到一個簡短的引導提示，協助完成初始設定。

使用 AI 回覆助手需要註冊帳戶嗎？

是的，您需要一個免費的 Donbrico 帳戶來啟用擴充功能。直接在擴充功能彈出視窗的引導畫面中註冊即可。這能讓您儲存語氣偏好設定，並在選擇自備模型時管理您的 API 金鑰。

安裝後第一件事該做什麼？

開啟任何訊息平台，例如 Gmail、客服工單介面或 Airbnb 訊息。點擊輸入欄位中的 Donbrico 圖示——擴充功能會自動讀取對話上下文。試著用預設語氣產生回覆，看看效果如何，再進一步自訂設定。

這個擴充功能只能用在電子郵件嗎？

當然不是。AI 回覆助手可以在瀏覽器中的任何文字輸入欄位運作——社群媒體留言、Slack 訊息、Zendesk 工單以及 Airbnb 收件匣。無需切換分頁或複製貼上內容；它會自動偵測您輸入處的對話內容。

功能與使用

擴充功能如何讀取我的對話上下文？

擴充功能會分析頁面上可見的文字，包括對話串或留言串中的先前訊息。它不會掃描您的完整瀏覽紀錄或不相關的分頁。這種上下文讀取功能讓 AI 能夠產生參考對話中特定重點的回覆。

我可以改變產生回覆的語氣嗎？

可以。開啟擴充功能彈出視窗，前往「語氣與風格」。您可以選擇預設選項，如專業、友善或簡潔，也可以撰寫自訂指令，例如「聽起來像一位熱情的 Airbnb 房東」。AI 會將此語氣套用到每則回覆，直到您再次變更。

發送前如何編輯回覆？

點擊「產生回覆」後，建議的文字會直接顯示在輸入欄位中。您可以像編輯一般訊息一樣進行修改——加入句子、更改詞語或刪除部分內容。擴充功能不會自動發送任何內容；在按下發送前，您擁有完全的控制權。

AI 回覆助手可以用在社群媒體留言嗎？

可以。前往任何社群媒體平台，如 LinkedIn、Twitter 或 Facebook。點擊留言框，Donbrico 圖示就會出現。擴充功能會讀取原始貼文和現有回覆，產生貼切且自然的留言。

它支援多種語言嗎？

AI 回覆助手在英文環境中表現最佳，但如果對話上下文是其他語言，它也能產生該語言的回覆。為獲得最佳效果，請在語氣設定中指定您偏好的語言。對於較不常見的語言，底層模型產生的回覆可能較不精準。

隱私與安全

我的對話資料在哪裡處理？

預設情況下，所有處理都在您裝置本地端使用 Gemini Nano 完成。您對話中的任何文字都不會傳送到外部伺服器。如果您選擇自備 API 金鑰（BYOK），資料會傳送給該供應商（例如 OpenAI）僅用於產生回覆，Donbrico 不會儲存或記錄這些資料。

Donbrico 會儲存我的訊息或回覆嗎？

不會。Donbrico 不會將您的對話紀錄、產生的回覆或任何個人資料儲存在其伺服器上。擴充功能僅在您瀏覽器本地端保留您的語氣偏好設定和 API 金鑰設定。您的隱私已內建於設計中——我們不會使用您的資料進行訓練。

如果我使用第三方的免費 API 金鑰會怎樣？

如果您啟用 BYOK 並使用第三方供應商（如 OpenAI），您的對話上下文會傳送到該供應商的伺服器以產生回覆。請查閱該供應商的隱私權政策，了解他們如何處理資料。您隨時可以在設定中切換回本地端 AI（Gemini Nano）。

這個擴充功能在工作帳戶上使用安全嗎？

安全。擴充功能不會存取您的登入憑證、密碼或付款資訊。它只會讀取目前輸入欄位中可見的文字。許多客服人員和自由工作者都在 Gmail 和 Zendesk 等工作平台上使用它，沒有安全疑慮。

價格與授權

AI 回覆助手有免費版本嗎？

有。免費版本包含使用 Gemini Nano 的無限本地端 AI 回覆以及基本語氣設定。您可以免費產生任意數量的回覆。自訂語氣指令和 BYOK 支援等進階功能則需要訂閱。

付費訂閱可以獲得什麼？

進階版可解鎖自備 API 金鑰（BYOK）功能，使用如 GPT-4 等更高品質的模型，以及進階語氣自訂功能，讓您撰寫詳細的風格指令。價格按月計算，可從您的 Donbrico 帳戶儀表板進行管理。

我可以隨時取消訂閱嗎？

可以。您隨時可以從 Donbrico 帳戶設定中取消進階訂閱。存取權限會持續到當前計費週期結束。取消後，您會回到僅有本地端 AI 的免費方案——資料不會遺失。

疑難排解

擴充功能圖示沒有顯示在我的訊息平台上。出了什麼問題？

首先，請確認擴充功能已釘選到工具列。如果仍未顯示，請重新整理頁面或重新啟動 Chrome。某些平台（如特定自訂網頁應用程式）可能需要您先點擊文字欄位。如果問題持續，請檢查擴充功能是否已在 Chrome 擴充功能清單中啟用。

產生的回覆與對話上下文不符。該如何修正？

這通常發生在擴充功能無法完整讀取對話串時。請嘗試向上捲動以載入較舊的訊息，讓它們顯示在畫面上，然後再次點擊 Donbrico 圖示。同時，檢查您的語氣設定是否覆蓋了上下文——將其重設為「中性」並重新產生。

我的 API 金鑰無法用於 BYOK 功能。該怎麼辦？

請確認您已從供應商儀表板複製完整的 API 金鑰，且沒有多餘空格。確認該金鑰具有有效的計費和您所選模型的權限。如果仍然失敗，請暫時切回本地端 AI，並將擴充功能中顯示的錯誤訊息提供給客服支援。

擴充功能讓我的瀏覽器變慢。有解決方法嗎？

本地端 AI 模型（Gemini Nano）可能會消耗一些系統資源。請關閉其他佔用資源的分頁或擴充功能以改善效能。如果您使用的是較低階的裝置，請考慮改用 BYOK 搭配雲端模型，這樣可以將處理作業轉移到供應商的伺服器。您也可以在不需要使用擴充功能的頁面上將其停用。
