AI 回复助手 — 常见问题解答

开始使用

如何安装 AI 回复助手扩展程序？

前往 Chrome 网上应用店，搜索 "Donbrico AI Reply Assistant"，然后点击"添加到 Chrome"。安装完成后，将扩展程序固定到工具栏以便快速访问。你会看到一个简短的新手引导提示，帮助完成初始设置。

使用 AI 回复助手需要注册账号吗？

是的，你需要一个免费的 Donbrico 账号来激活扩展程序。直接在扩展程序弹窗内的引导界面注册即可。这样你可以保存语气偏好，并在选择自带模型时管理你的 API 密钥。

安装后第一件事应该做什么？

打开任意消息平台，比如 Gmail、客服工单界面或 Airbnb 消息。点击输入框中的 Donbrico 图标——扩展程序会自动读取对话上下文。先用默认语气尝试生成一条回复，看看效果如何，然后再自定义设置。

这个扩展程序只能用于邮件吗？

当然不是。AI 回复助手适用于浏览器内的任何文本输入框——社交媒体评论、Slack 消息、Zendesk 工单和 Airbnb 收件箱都可以。无需切换标签页或复制粘贴内容；它能在你输入的任何地方检测对话。

功能与使用

扩展程序如何读取我的对话上下文？

扩展程序会分析页面上可见的文本，包括对话线程或评论链中的历史消息。它不会扫描你的整个浏览历史或不相关的标签页。这种上下文读取能力让 AI 能够生成引用对话中具体内容的回复。

我可以更改生成回复的语气吗？

可以。打开扩展程序弹窗，进入"语气与风格"选项。你可以选择预设模式，如专业、友好或简洁，也可以编写自定义指令，例如"听起来像一位热心的 Airbnb 房东"。AI 会将该语气应用到所有回复，直到你更改设置。

发送前如何编辑回复？

点击"生成回复"后，建议的文本会直接出现在输入框中。你可以像编辑普通消息一样进行修改——添加句子、更改词语或删除部分内容。扩展程序不会自动发送任何内容；在点击发送前你拥有完全的控制权。

我可以用 AI 回复助手处理社交媒体评论吗？

可以。前往任意社交媒体平台，如 LinkedIn、Twitter 或 Facebook。点击评论框内部，Donbrico 图标就会出现。扩展程序会读取原始帖子和现有评论，从而生成相关且自然的评论内容。

它支持多种语言吗？

AI 回复助手在英语环境下表现最佳，但如果对话上下文是其他语言，它也可以生成相应语言的回复。为获得最佳效果，请在语气设置中指定你偏好的语言。对于不常用的语言，底层模型生成的回复可能不够准确。

隐私与安全

我的对话数据在哪里处理？

默认情况下，所有处理都在你的设备上本地进行，使用 Gemini Nano。你的对话文本不会发送到外部服务器。如果你选择自带 API 密钥（BYOK），数据会发送给该提供商（如 OpenAI）仅用于生成回复，Donbrico 不会存储或记录这些数据。

Donbrico 会存储我的消息或回复吗？

不会。Donbrico 不会在其服务器上存储你的对话历史、生成的回复或任何个人数据。扩展程序仅在你的浏览器本地保留语气偏好和 API 密钥设置。隐私保护是设计的一部分——我们不会用你的数据进行训练。

如果我使用第三方的免费 API 密钥会怎样？

如果你启用 BYOK 并使用第三方提供商（如 OpenAI），你的对话上下文会被发送到该提供商的服务器以生成回复。请查阅该提供商的隐私政策，了解他们如何处理数据。你可以在设置中随时切换回本地 AI（Gemini Nano）。

这个扩展程序在工作账号上使用安全吗？

安全。扩展程序不会访问你的登录凭证、密码或支付信息。它只读取活动输入框中可见的文本。许多客服人员和自由职业者都在 Gmail 和 Zendesk 等工作平台上使用它，没有安全问题。

定价与许可

AI 回复助手有免费版本吗？

有。免费版本包括使用 Gemini Nano 的无限本地 AI 回复和基本语气设置。你可以免费生成任意数量的回复。高级功能如自定义语气指令和 BYOK 支持需要订阅。

高级订阅能获得什么？

高级版解锁了自带 API 密钥（BYOK）的功能，可使用 GPT-4 等更高质量的模型，以及高级语气定制功能，你可以编写详细的风格指令。按月定价，可通过你的 Donbrico 账号面板管理。

我可以随时取消订阅吗？

可以。你可以随时从你的 Donbrico 账号设置中取消高级订阅。访问权限将持续到当前计费周期结束。取消后，你将恢复到仅限本地 AI 的免费计划——不会丢失任何数据。

故障排除

扩展程序图标没有出现在我的消息平台上。出了什么问题？

首先，确保扩展程序已固定到工具栏。如果仍然不显示，请刷新页面或重启 Chrome。某些平台（如特定的自定义网页应用）可能需要你先点击文本输入框。如果问题依旧，请检查扩展程序是否已在 Chrome 扩展程序列表中启用。

生成的回复与对话上下文不匹配。如何解决？

这通常是因为扩展程序无法完整读取对话线程。尝试向上滚动以加载历史消息，使它们显示在屏幕上，然后再次点击 Donbrico 图标。同时，检查你的语气设置是否覆盖了上下文——将其重置为"中性"并重新生成。

我的 API 密钥在 BYOK 功能中无法使用。该怎么办？

确保你从提供商面板复制了完整的 API 密钥，且没有多余空格。验证该密钥是否具有活跃的计费状态和所选模型的权限。如果仍然失败，暂时切换回本地 AI，并附上扩展程序中显示的错误消息联系支持团队。

扩展程序拖慢了浏览器速度。有解决方法吗？

本地 AI 模型（Gemini Nano）会消耗一些系统资源。关闭其他占用资源较多的标签页或扩展程序以提高性能。如果你使用的是低端设备，可以考虑使用 BYOK 配合云端模型，这样可以将处理任务卸载到提供商的服务器。你也可以在不需要使用扩展程序的页面上禁用它。
