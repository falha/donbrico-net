propertyfill — 常见问题解答

入门指南

如何安装 propertyfill 浏览器扩展？

安装 propertyfill 只需大约两分钟。访问 Chrome 网上应用店或您浏览器的扩展市场，搜索 "propertyfill by Donbrico"，然后点击"添加到扩展程序"。安装完成后，将扩展固定到工具栏，点击图标打开设置面板，您可以在其中配置默认语言和提供商设置。

首次使用 propertyfill 需要准备什么？

您需要一个受支持的浏览器（Chrome、Edge 或 Firefox），以及用于初始下载的活跃网络连接。扩展程序本身完全在设备端运行，因此除非您使用自定义 BYOK 设置，否则无需创建账户或提供 API 密钥。安装后，只需打开任意 MLS 或 CRM 文本字段，开始输入原始笔记即可。

如何使用 propertyfill 生成我的第一条房源信息？

安装后，导航到 MLS 系统或 CRM 中的任意房源输入字段。在文本框中输入或粘贴您的原始经纪人笔记，然后点击浏览器工具栏中的 propertyfill 图标，选择"生成房源"。AI 将在本地处理您的笔记，并在几秒钟内生成双语描述、设施清单和逐房间详情。

propertyfill 能否与我现有的 MLS 或 CRM 平台配合使用？

可以，propertyfill 被设计为一个浏览器扩展，可在您现有的基于网页的工具之上运行。它与任何使用标准文本输入字段的平台集成，包括主流的 MLS 系统、CRM 平台和自定义物业管理软件。只要您能在网页上的字段中输入笔记，propertyfill 就能处理它们。

功能与使用

propertyfill 如何生成英法双语房源信息？

首次设置 propertyfill 时，您可以选择偏好的输出语言或选择"双语"。设备端 AI 随后会生成每套带有平行英法描述的房源信息，包括房间详情、设施清单和 SEO 关键词。这专为魁北克房地产专业人士打造，他们需要合规的双语内容，而无需手动翻译。

"幻觉防护"功能究竟能防止什么？

幻觉防护是一个安全层，用于扫描 AI 输出中是否存在编造的数据点，如虚假的 MLS 编号、虚构的平方英尺数或捏造的价格。如果 AI 生成了任何此类信息，防护层会在房源信息显示前自动删除或纠正它们。这可以防止常见的 AI 问题——即"幻觉"出看似真实但虚假的信息，从而避免违反合规要求或误导买家。

propertyfill 能否逐房间分解房源信息？

可以。当您提供的笔记中提到房间时，propertyfill 会自动生成带有独立描述的逐房间分解。例如，"更新厨房配石英台面，主卧带步入式衣帽间"这样的笔记会变成厨房和主卧室各自独立的、经过润色的段落。如果您的笔记结构不够清晰，您也可以从扩展面板手动触发逐房间生成。

SEO 关键词和设施清单生成是如何工作的？

Propertyfill 会分析您的原始笔记和生成的房源文本，提取相关的关键词和设施。它会构建一个易于搜索的术语列表（例如"开放式布局"、"花岗岩台面"、"硬木地板"）和一个独立的设施清单。两者均以您选择的语言输出，并可直接复制到您房源信息的元数据或特性字段中。

我可以自定义生成描述的语气或长度吗？

目前，propertyfill 使用针对房地产房源优化过的专业、精炼语气。您可以通过组织原始笔记的方式来影响输出——更详细的笔记会产生更详尽的房源描述。未来更新可能会包含语气预设，但核心设计优先考虑准确性和完整性，而非风格变化。

隐私与安全

propertyfill 在哪里处理我的数据——在我的设备上还是在云端？

所有 AI 处理完全在您的设备上完成。当您点击"生成房源"时，您的原始笔记会由存储在浏览器扩展中的 AI 模型在本地处理。没有任何数据——无论是您的笔记、生成的房源信息，还是任何房产详情——会被发送到 Donbrico 的服务器或任何第三方云服务。

propertyfill 会存储或记录我的房源数据吗？

不会。Propertyfill 不会存储、记录或缓存您的任何房源数据。一旦 AI 生成输出并在扩展面板中显示，原始笔记和生成的内容仅存在于浏览器的临时内存中。关闭扩展或刷新页面会清除所有内容。Donbrico 无法访问您的房源信息。

我的经纪公司能否审计或监控 propertyfill 生成的内容？

由于所有处理都在本地进行，且没有任何数据离开您的浏览器，propertyfill 不会创建任何服务器端日志或审计记录。您的经纪公司只有在您将最终房源信息粘贴到 MLS 或 CRM 后才会看到它——这与您手动输入的情况相同。如果您的经纪公司需要内部日志记录，您需要通过现有的工作流程工具来实现。

propertyfill 与基于云的房地产 AI 写作工具有何不同？

基于云的工具会将您的笔记和房产详情发送到外部服务器进行处理，这会产生潜在的隐私风险和数据保留问题。Propertyfill 将所有内容保留在您的设备上——您的笔记永远不会接触网络。这也意味着在初始下载后它可以离线工作，并且没有与 API 使用相关的订阅费用。

定价与许可

propertyfill 是免费使用，还是有付费版本？

Propertyfill 采用免费增值模式。免费套餐每月包含有限次数的房源生成，足以满足偶尔使用或测试需求。高级套餐提供无限次生成、优先使用新功能，以及使用您自己的 API 密钥（BYOK）自定义 AI 模型的能力。定价详情请访问 Donbrico 定价页面。

BYOK 选项是什么意思？谁需要它？

BYOK 代表"自带密钥"。如果您的经纪公司有偏好的 AI 提供商，或者您想使用特定模型，您可以在 propertyfill 的设置中输入自己的 API 密钥。这对于已经拥有 AI 合同或希望确保与公司批准的模型保持一致的机构非常有用。免费套餐使用 Donbrico 的默认设备端模型。

如果 propertyfill 不适合我的工作流程，我可以获得退款吗？

可以，Donbrico 为高级订阅提供 14 天退款保证。如果 propertyfill 在前两周内不适合您的工作流程或未能达到您的期望，请联系支持人员以获得全额退款。免费套餐用户可以在决定付费计划之前免费测试该扩展。

故障排除

点击按钮后，propertyfill 没有生成任何内容。出了什么问题？

首先，检查扩展是否已固定并在工具栏中处于活动状态——有时浏览器更新会禁用扩展。接下来，确保您已在页面上的输入字段中输入了文本；propertyfill 不会从空字段生成内容。如果仍然无法工作，请尝试刷新页面或重启浏览器。持续存在的问题可能需要从市场重新安装扩展。

生成的房源信息包含错误信息或缺失详情。

这通常发生在您的原始笔记过于模糊或包含歧义词句时。Propertyfill 在处理具体、结构化的笔记时效果最佳（例如"3 间卧室，2 间浴室，2022 年翻新厨房，全屋硬木地板"）。如果 AI 误解了某些内容，您可以在复制之前直接在扩展面板中编辑输出。对于反复出现的不准确情况，请仔细检查您的笔记是否包含矛盾信息。

propertyfill 没有检测到我的 MLS 或 CRM 平台字段。

一些自定义或较旧的平台使用非标准输入字段，propertyfill 可能无法自动识别。请尝试在激活扩展之前直接点击文本字段。如果仍然无法检测到该字段，请使用扩展面板中的"手动模式"选项，将您的笔记直接粘贴到 propertyfill 中，然后将生成的输出复制回您的平台。

扩展程序导致我的浏览器变慢或崩溃。

设备端 AI 处理会使用您计算机的 CPU 和内存。如果您同时运行多个大型应用程序（如视频编辑软件或多个浏览器标签页），propertyfill 可能会导致卡顿。在生成房源信息前关闭不必要的标签页或应用程序。如果崩溃持续存在，您的设备可能未达到最低系统要求——请查看 Donbrico 支持页面以获取硬件建议。
