propertyfill — 常見問題

開始使用

如何安裝 propertyfill 瀏覽器擴充功能？

安裝 propertyfill 大約需要兩分鐘。前往 Chrome 線上應用程式商店或您瀏覽器的擴充功能市集，搜尋「propertyfill by Donbrico」，然後點擊「加到擴充功能」。安裝完成後，將擴充功能釘選到工具列，並點擊圖示開啟設定面板，即可設定預設語言和供應商選項。

首次使用 propertyfill 前需要準備什麼？

您需要一個支援的瀏覽器（Chrome、Edge 或 Firefox）以及用於初始下載的穩定網路連線。擴充功能本身完全在裝置端執行，因此無需建立帳戶或 API 金鑰，除非您使用自訂的 BYOK 設定。安裝後，只需開啟任何 MLS 或 CRM 文字欄位，並開始輸入原始筆記即可。

如何使用 propertyfill 生成我的第一份房源？

安裝後，導航至 MLS 系統或 CRM 中的任何房源輸入欄位。在文字框中輸入或貼上您的原始經紀人筆記，然後點擊瀏覽器工具列中的 propertyfill 圖示，選擇「生成房源」。AI 會在本機處理您的筆記，並在幾秒鐘內生成雙語描述、設施清單和逐房詳細資訊。

propertyfill 能與我現有的 MLS 或 CRM 平台搭配使用嗎？

可以，propertyfill 被設計為一個瀏覽器擴充功能，可在您現有的網頁工具上運作。它與任何使用標準文字輸入欄位的平台整合，包括熱門的 MLS 系統、CRM 平台和自訂物業管理軟體。只要您能在網頁的欄位中輸入筆記，propertyfill 就能處理它們。

功能與使用

propertyfill 如何生成英語和法語的雙語房源？

首次設定 propertyfill 時，您可以選擇偏好的輸出語言或選擇「雙語」。裝置端 AI 隨後會為每份房源生成平行的英語和法語描述，包括房間細節、設施清單和 SEO 關鍵字。這專為需要合規雙語內容而無需手動翻譯的魁北克房地產專業人士打造。

「幻覺防護」實際上能防止什麼？

幻覺防護是一個安全層，用於掃描 AI 輸出中是否存在虛構的數據點，例如偽造的 MLS 號碼、虛構的平方英尺或捏造的價格。如果 AI 生成任何此類內容，防護機制會在房源顯示前自動刪除或修正它們。這能防止常見的 AI「幻覺」問題，避免生成看似真實但虛假的資訊，以免違反合規要求或誤導買家。

propertyfill 能逐房拆解房源嗎？

可以。當您提供的筆記中提到房間時，propertyfill 會自動生成逐房細項說明，並附上各自的描述。例如，筆記中寫「翻新廚房配石英檯面，主臥有步入式衣櫥」時，會分別生成關於廚房和主臥室的完整段落。如果您的筆記結構較鬆散，也可以從擴充功能面板手動觸發逐房生成。

SEO 關鍵字和設施清單的生成機制為何？

Propertyfill 會分析您的原始筆記和生成的房源文字，從中提取相關的關鍵字和設施。它會建立一份搜尋友好的詞彙清單（例如「開放式設計」、「花崗岩檯面」、「硬木地板」）以及一份獨立的設施核對清單。兩者皆以您選擇的語言輸出，並可直接複製到房源的元數據或功能欄位中。

我可以自訂生成描述的語氣或長度嗎？

目前，propertyfill 使用專業且精煉的語氣，專為房地產房源優化。您可以透過原始筆記的措辭方式影響輸出結果——更具描述性的筆記會產生更詳細的房源。未來更新可能包含語氣預設選項，但核心設計優先考慮準確性和完整性，而非風格變化。

隱私與安全

propertyfill 在哪裡處理我的數據——在我的裝置上還是雲端？

所有 AI 處理完全在您的裝置上進行。當您點擊「生成房源」時，您的原始筆記會由儲存在瀏覽器擴充功能中的 AI 模型在本機處理。沒有任何數據——無論是您的筆記、生成的房源還是任何物業詳細資訊——會被傳送到 Donbrico 的伺服器或任何第三方雲端服務。

propertyfill 會儲存或記錄我的房源數據嗎？

不會。Propertyfill 不會儲存、記錄或快取您的任何房源數據。一旦 AI 生成輸出並顯示在擴充功能面板中，原始筆記和生成的內容僅存在於瀏覽器的暫存記憶體中。關閉擴充功能或重新整理頁面會清除所有內容。Donbrico 無法存取您的房源。

我的經紀公司可以稽核或監控 propertyfill 生成的內容嗎？

由於所有處理都在本機進行，且沒有數據離開您的瀏覽器，因此 propertyfill 不會產生任何伺服器端的日誌或稽核軌跡。您的經紀公司只會在您將最終房源貼入 MLS 或 CRM 後看到它——這與您手動輸入的情況相同。如果您的經紀公司需要內部記錄，您需要透過現有的工作流程工具自行實現。

propertyfill 與雲端型 AI 房地產寫作工具有何不同？

雲端工具會將您的筆記和物業詳細資訊傳送到外部伺服器進行處理，這會產生潛在的隱私風險和數據保留問題。Propertyfill 將一切保留在您的裝置上——您的筆記從不接觸網路。這也意味著在初始下載後，它可以在離線狀態下運作，並且沒有與 API 使用相關的訂閱費用。

定價與授權

propertyfill 是免費使用，還是需要付費版本？

Propertyfill 採用免費增值模式。免費方案每月包含有限次數的房源生成，足以應付偶爾使用或測試。高級方案提供無限次生成、優先使用新功能，以及使用您自己的 API 金鑰（BYOK）來客製化 AI 模型的能力。定價詳情請參閱 Donbrico 定價頁面。

BYOK 選項是什麼意思？誰需要它？

BYOK 代表「自備金鑰」。如果您的經紀公司有偏好的 AI 供應商，或您想使用特定模型，您可以在 propertyfill 的設定中輸入自己的 API 金鑰。這對於已簽訂 AI 合約的機構，或希望確保與公司核准模型一致性的機構很有用。免費方案使用 Donbrico 預設的裝置端模型。

如果 propertyfill 不適合我的工作流程，可以退款嗎？

可以，Donbrico 為高級訂閱提供 14 天退款保證。如果 propertyfill 在頭兩週內不符合您的工作流程或期望，請聯絡支援團隊以獲得全額退款。免費方案使用者可以在決定付費方案前，免費測試擴充功能。

故障排除

我點擊按鈕後 propertyfill 沒有生成任何內容。出了什麼問題？

首先，檢查擴充功能是否已釘選並在工具列中啟用——有時瀏覽器更新會停用擴充功能。接著，確認您已在頁面的輸入欄位中輸入文字；propertyfill 不會從空白欄位生成內容。如果仍然無效，請嘗試重新整理頁面或重新啟動瀏覽器。持續存在的問題可能需要從應用程式市集重新安裝擴充功能。

生成的房源包含不正確的資訊或遺漏細節。

這通常發生在您的原始筆記過於模糊或包含含糊詞彙時。Propertyfill 在處理具體且有結構的筆記時效果最佳（例如「3 間臥室、2 間衛浴、2022 年翻新廚房、全屋硬木地板」）。如果 AI 誤解了某些內容，您可以在複製前直接在擴充功能面板中編輯輸出。對於反覆出現的不準確情況，請仔細檢查您的筆記是否包含矛盾資訊。

propertyfill 無法偵測我的 MLS 或 CRM 平台欄位。

某些自訂或較舊的平台使用非標準的輸入欄位，propertyfill 可能無法自動識別它們。請嘗試在啟動擴充功能前直接點擊文字欄位。如果仍然無法偵測到欄位，請使用擴充功能面板中的「手動模式」選項，將您的筆記直接貼入 propertyfill，然後將生成的輸出複製回您的平台。

擴充功能拖慢了我的瀏覽器速度或導致當機。

裝置端 AI 處理會使用您電腦的 CPU 和 RAM。如果您同時執行多個重量級應用程式（例如影片編輯軟體或大量瀏覽器分頁），propertyfill 可能會導致延遲。在生成房源前，關閉不必要的分頁或應用程式。如果當機問題持續發生，您的裝置可能不符合最低系統需求——請查閱 Donbrico 支援頁面以了解硬體建議。
