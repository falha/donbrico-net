MedAutoFill — 常見問題

開始使用

如何在瀏覽器上安裝 MedAutoFill？

MedAutoFill 是一款 Chrome 擴充功能。請前往 Chrome 線上應用程式商店，搜尋「MedAutoFill by Donbrico」，然後點選「加到 Chrome」。安裝完成後，您會在瀏覽器工具列看到 MedAutoFill 圖示，接著即可開啟設定指南，開始建立您的第一份病患資料檔。

初次安裝 MedAutoFill 後，我需要做什麼？

安裝完成後，請開啟 MedAutoFill 擴充功能面板，點選「新增資料檔」來輸入第一位病患的基本資料、保險資訊及醫療提供者資訊。您也可以設定 BYOK（自備金鑰）AI 功能，以處理較複雜的欄位。無需註冊帳號——您的資料從一開始就保留在本機端。

MedAutoFill 能與我特定的 EHR 或保險入口網站相容嗎？

MedAutoFill 專為廣泛的 EHR 系統、保險入口網站及醫療辦公室軟體而設計。若遇到無法辨識的表單或欄位，您可以使用「智慧欄位偵測」訓練工具來教導它辨識新的版面配置。多數使用者發現，它能立即與 Epic、Cerner 及 Practice Fusion 等主要平台搭配使用。

MedAutoFill 可以馬上使用，還是需要學習曲線？

您可以在幾分鐘內開始自動填寫表單。擴充功能內建常用欄位的預設範本，例如病患姓名、出生日期及保險 ID。學習曲線極低——多數行政人員在填寫完前兩、三份測試表單後就能上手。

功能與使用

MedAutoFill 如何處理複雜或非標準的表單欄位？

MedAutoFill 使用兩層機制：規則引擎處理標準欄位（姓名、出生日期、保險 ID），而 BYOK AI 層則處理「主訴」或「預先授權備註」等複雜欄位。您可以連接自己的 OpenAI API 金鑰來啟用 AI 驅動的建議，或僅使用內建的欄位偵測功能進行手動資料輸入。

我可以在 MedAutoFill 中儲存多份病患資料檔嗎？

可以，MedAutoFill 支援多份病患資料檔。您可以從擴充功能面板建立、編輯及切換資料檔。這對每天處理數十位病患的醫療帳務人員與編碼員特別有用——只需在自動填寫表單前選取正確的資料檔即可。

智慧欄位偵測功能如何運作？

當您點選表單欄位時，MedAutoFill 會掃描頁面上的標籤、預留位置文字及附近的 HTML 元素，以判斷該欄位要求的內容（例如「保險團體編號」或「轉診提供者 NPI」）。接著，它會將該欄位對應到您所選病患資料檔中的正確資料。若欄位無法辨識，您可以手動指定一次，MedAutoFill 會記住此對應關係，供未來表單使用。

MedAutoFill 能在多頁表單與精靈流程中運作嗎？

可以，MedAutoFill 專為處理多頁表單與逐步精靈而設計。當您移至下一頁時，擴充功能會根據您啟用的病患資料檔自動偵測並填寫相關欄位。您無需重新選取資料檔或重新觸發填寫動作。

MedAutoFill 能同時用於病患基本資料與臨床欄位嗎？

當然可以。MedAutoFill 涵蓋病患基本資料（姓名、地址、聯絡資訊）、保險資訊（保險公司、保單號碼、團體編號）、醫療提供者詳細資料（NPI、分類代碼、轉診醫師）以及臨床欄位（診斷碼、主訴、用藥清單）。您可以自訂每個資料檔中要包含的欄位。

隱私與安全性

使用 MedAutoFill 時，我的病患資料儲存在哪裡？

您在 MedAutoFill 中輸入的所有病患資料均使用瀏覽器儲存空間，儲存在您的本機裝置上。資料不會上傳至 Donbrico 的伺服器或任何第三方雲端。除非您明確連接 BYOK AI 服務，否則您的資料絕不會離開您的電腦。

MedAutoFill 是否符合 HIPAA 規範？

MedAutoFill 採用隱私優先的架構設計，支援 HIPAA 合規性。由於所有資料都保留在您的本機裝置上，因此不會將資料傳輸至 Donbrico 的伺服器。針對 BYOK AI 功能，您可控制 API 金鑰，並選擇 OpenAI 企業層級等符合 HIPAA 規範的提供者。我們建議您諮詢所屬機構的合規專員，以確認特定工作流程。

如果我使用 BYOK AI 功能，我的資料會傳送到 OpenAI 嗎？

當您啟用 BYOK AI 並連接自己的 API 金鑰時，僅有您正在填寫的特定欄位資料（例如臨床備註）會傳送至您設定的 AI 提供者。病患姓名與出生日期等標準欄位絕不會傳送給 AI。您也可以完全停用 AI 功能，僅使用 MedAutoFill 的規則式填寫。

我的雇主或診所能看到我在 MedAutoFill 中輸入的資料嗎？

不能。MedAutoFill 將資料儲存在瀏覽器的本機儲存空間中，此空間與其他應用程式及擴充功能隔離。除非您的雇主能直接存取您的裝置，否則他們無法查看您的 MedAutoFill 資料。若使用共用工作站，我們建議在每次使用後點選「清除資料檔」選項。

定價與授權

MedAutoFill 是免費使用，還是有付費版本？

MedAutoFill 提供免費方案，支援最多 5 份病患資料檔及標準欄位偵測。付費版本則解鎖無限病患資料檔、進階欄位對應及 BYOK AI 整合功能。請前往 Donbrico 網站查看當前定價，以及診所或帳務團隊適用的數量折扣。

我可以在多個裝置上或與團隊共用一個 MedAutoFill 授權嗎？

授權與個別的 Chrome 設定檔綁定。團隊使用時，每位使用者需要自己的授權。Donbrico 為診所及帳務機構提供團隊與企業定價——請透過網站聯絡銷售人員以取得客製化方案。

付費功能有免費試用期嗎？

有，MedAutoFill 提供 14 天付費功能免費試用，包括無限資料檔與 BYOK AI。開始試用無需信用卡。試用期結束後，您可以選擇訂閱或繼續使用免費方案。

疑難排解

MedAutoFill 沒有填寫我表單上的某個欄位——該怎麼辦？

首先，請確認您已選取正確的病患資料檔。接著，點選未填寫的欄位，檢查 MedAutoFill 圖示是否出現。若未出現，該欄位可能使用了非標準的 HTML。請使用擴充功能中的「教導欄位」選項，手動將其對應到正確的資料點。只需教導一次，MedAutoFill 就會記住該表單的對應關係。

在某些網站上，擴充功能圖示是灰色的——為什麼？

MedAutoFill 設計為僅在醫療與保健表單頁面上啟用。若圖示為灰色，表示擴充功能未將該頁面辨識為相容表單。您可以右鍵點選圖示，選擇「在此網站上啟用」來手動啟用。若該網站仍無法運作，可能使用了 iframe 或 Java applet 等不受支援的技術。

我不小心刪除了一份病患資料檔——可以復原嗎？

很遺憾，由於所有資料均儲存在本機且無雲端備份，MedAutoFill 無法復原已刪除的資料檔。我們建議您定期使用設定面板中的「匯出資料檔」功能，將資料檔匯出為 JSON 檔案，以便日後重新匯入。

MedAutoFill 將錯誤的資料填入某些欄位——該如何修正？

這通常是智慧欄位偵測誤判欄位所致。請開啟 MedAutoFill 面板，前往「欄位對應」，找到有問題的欄位，然後將其重新指定為病患資料檔中的正確資料點。或者，您可以清除該表單的所有欄位對應，並選取「重設表單訓練」來重新開始。

MedAutoFill 能在離線狀態下使用嗎？

MedAutoFill 可在離線狀態下使用規則式填寫及已儲存的病患資料檔。BYOK AI 功能需要網際網路連線才能與 AI 提供者通訊。對於大多數標準表單，您可以在無網路環境下工作——只需確保在連線時已載入您的資料檔即可。
