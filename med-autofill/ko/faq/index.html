MedAutoFill — 자주 묻는 질문

시작하기

MedAutoFill을 브라우저에 어떻게 설치하나요?

MedAutoFill은 Chrome 확장 프로그램입니다. Chrome 웹 스토어에 접속하여 "Donbrico의 MedAutoFill"을 검색한 후 "Chrome에 추가"를 클릭하세요. 설치가 완료되면 브라우저 툴바에서 MedAutoFill 아이콘을 확인할 수 있으며, 설정 가이드를 열어 첫 번째 환자 프로필을 만들 수 있습니다.

MedAutoFill을 처음 설치한 후에는 무엇을 해야 하나요?

설치 후 MedAutoFill 확장 프로그램 패널을 열고 "새 프로필"을 클릭하여 첫 번째 환자의 인구통계 정보, 보험 세부사항, 제공자 정보를 입력하세요. 복잡한 필드를 위해 BYOK(Bring Your Own Key) AI 설정도 구성할 수 있습니다. 계정 등록은 필요하지 않으며, 처음부터 모든 데이터는 로컬에 저장됩니다.

MedAutoFill이 제가 사용하는 특정 EHR이나 보험 포털에서 작동하나요?

MedAutoFill은 다양한 EHR 시스템, 보험 포털, 의료 사무용 소프트웨어에서 작동하도록 설계되었습니다. 인식하지 못하는 양식이나 필드가 있을 경우 "스마트 필드 감지" 학습 도구를 사용하여 새로운 레이아웃을 가르칠 수 있습니다. 대부분의 사용자는 Epic, Cerner, Practice Fusion과 같은 주요 플랫폼에서 별도 설정 없이 바로 사용할 수 있습니다.

MedAutoFill을 바로 사용할 수 있나요, 아니면 학습 시간이 필요한가요?

몇 분 안에 양식 자동 입력을 시작할 수 있습니다. 확장 프로그램에는 환자 이름, 생년월일, 보험 ID와 같은 일반적인 필드에 대한 사전 구성 템플릿이 포함되어 있습니다. 학습 곡선은 최소화되어 있으며, 대부분의 행정 직원은 두세 개의 테스트 양식을 작성한 후 바로 생산적으로 사용할 수 있습니다.

기능 및 사용법

MedAutoFill은 복잡하거나 비표준 양식 필드를 어떻게 처리하나요?

MedAutoFill은 두 가지 레이어를 사용합니다: 표준 필드(이름, 생년월일, 보험 ID)용 규칙 기반 엔진과 "주 호소" 또는 "사전 승인 메모"와 같은 복잡한 필드용 BYOK AI 레이어입니다. 자체 OpenAI API 키를 연결하여 AI 기반 제안을 활성화하거나, 수동 데이터 입력을 위해 내장된 필드 감지만 사용할 수 있습니다.

MedAutoFill에 여러 환자 프로필을 저장할 수 있나요?

네, MedAutoFill은 여러 환자 프로필을 지원합니다. 확장 프로그램 패널에서 프로필을 생성, 편집, 전환할 수 있습니다. 이 기능은 하루에 수십 명의 환자를 처리하는 의료 청구 및 코딩 담당자에게 특히 유용합니다. 양식을 자동 입력하기 전에 올바른 프로필만 선택하면 됩니다.

스마트 필드 감지 기능은 어떻게 작동하나요?

양식 필드를 클릭하면 MedAutoFill이 페이지의 레이블, 플레이스홀더 텍스트, 주변 HTML 요소를 스캔하여 필드가 요청하는 내용(예: "보험 그룹 번호" 또는 "의뢰 제공자 NPI")을 식별합니다. 그런 다음 해당 필드를 선택한 환자 프로필의 올바른 데이터에 매핑합니다. 필드가 인식되지 않으면 한 번 수동으로 할당할 수 있으며, MedAutoFill이 이후 양식에서 해당 매핑을 기억합니다.

MedAutoFill은 여러 페이지로 구성된 양식과 마법사에서 작동하나요?

네, MedAutoFill은 여러 페이지 양식과 단계별 마법사를 처리하도록 설계되었습니다. 다음 페이지로 이동하면 확장 프로그램이 활성 환자 프로필을 기반으로 관련 필드를 자동으로 감지하여 입력합니다. 프로필을 다시 선택하거나 입력을 다시 트리거할 필요가 없습니다.

MedAutoFill을 환자 인구통계 정보와 임상 필드 모두에 사용할 수 있나요?

물론입니다. MedAutoFill은 환자 인구통계(이름, 주소, 연락처 정보), 보험 정보(보험사, 증권번호, 그룹번호), 제공자 세부정보(NPI, 진료과목, 의뢰 의사), 임상 필드(진단 코드, 주 호소, 투약 목록)를 모두 다룹니다. 각 프로필에 포함할 필드를 직접 맞춤 설정할 수 있습니다.

개인정보 보호 및 보안

MedAutoFill을 사용할 때 환자 데이터는 어디에 저장되나요?

MedAutoFill에 입력한 모든 환자 데이터는 브라우저 저장소를 사용하여 사용자 기기에 로컬로 저장됩니다. Donbrico의 서버나 타사 클라우드에 업로드되는 데이터는 없습니다. BYOK AI 서비스를 명시적으로 연결하지 않는 한 데이터가 컴퓨터를 떠나지 않습니다.

MedAutoFill은 HIPAA를 준수하나요?

MedAutoFill은 HIPAA 규정 준수를 지원하는 개인정보 보호 우선 아키텍처로 설계되었습니다. 모든 데이터는 사용자 기기에 로컬로 유지되므로 Donbrico 서버로 데이터가 전송되지 않습니다. BYOK AI 기능의 경우 API 키를 직접 제어하며 OpenAI의 엔터프라이즈 티어와 같은 HIPAA 규격 제공자를 선택할 수 있습니다. 특정 워크플로에 대해서는 기관의 규정 준수 책임자와 상담하는 것이 좋습니다.

BYOK AI 기능을 사용하면 내 데이터가 OpenAI로 전송되나요?

BYOK AI를 활성화하고 자체 API 키를 연결하면 입력 중인 특정 필드(예: 임상 노트)의 데이터가 설정한 AI 제공자로 전송됩니다. 환자 이름과 생년월일 같은 표준 필드는 AI로 전송되지 않습니다. AI 기능을 완전히 비활성화하고 MedAutoFill의 규칙 기반 입력만 사용할 수도 있습니다.

고용주나 클리닉에서 내가 MedAutoFill에 입력하는 데이터를 볼 수 있나요?

아니요. MedAutoFill은 다른 애플리케이션 및 확장 프로그램과 샌드박스 처리된 브라우저 저장소에 데이터를 로컬로 저장합니다. 고용주가 사용자 기기에 직접 접근할 수 없는 한 MedAutoFill 데이터에 접근할 수 없습니다. 공유 워크스테이션 사용 시 각 세션 후 "프로필 지우기" 옵션을 사용하는 것이 좋습니다.

가격 및 라이선스

MedAutoFill은 무료인가요, 아니면 프리미엄 버전이 있나요?

MedAutoFill은 최대 5개의 환자 프로필과 표준 필드 감지를 지원하는 무료 티어를 제공합니다. 프리미엄 버전은 무제한 환자 프로필, 고급 필드 매핑, BYOK AI 통합을 제공합니다. 현재 가격과 클리닉 또는 청구 팀을 위한 볼륨 할인은 Donbrico 웹사이트를 확인하세요.

하나의 MedAutoFill 라이선스를 여러 기기나 팀과 함께 사용할 수 있나요?

라이선스는 개별 Chrome 프로필에 연결됩니다. 팀 사용의 경우 각 사용자가 자체 라이선스를 필요로 합니다. Donbrico는 클리닉 및 청구 기관을 위한 팀 및 엔터프라이즈 가격을 제공합니다. 맞춤 플랜은 웹사이트를 통해 영업팀에 문의하세요.

프리미엄 기능에 대한 무료 체험판이 있나요?

네, MedAutoFill은 무제한 프로필과 BYOK AI를 포함한 프리미엄 기능의 14일 무료 체험판을 제공합니다. 체험판 시작에 신용카드는 필요하지 않습니다. 체험판 종료 후 구독하거나 무료 티어를 계속 사용할 수 있습니다.

문제 해결

MedAutoFill이 내 양식의 특정 필드를 채우지 않습니다. 어떻게 해야 하나요?

먼저 올바른 환자 프로필을 선택했는지 확인하세요. 그런 다음 채워지지 않은 필드를 클릭하고 MedAutoFill 아이콘이 나타나는지 확인하세요. 나타나지 않으면 해당 필드가 비표준 HTML을 사용하는 것일 수 있습니다. 확장 프로그램의 "필드 학습" 옵션을 사용하여 올바른 데이터 포인트에 수동으로 매핑하세요. 한 번 학습시키면 MedAutoFill이 해당 양식의 매핑을 기억합니다.

일부 웹사이트에서 확장 프로그램 아이콘이 회색으로 표시됩니다. 왜 그런가요?

MedAutoFill은 의료 및 헬스케어 양식 페이지에서만 활성화되도록 설계되었습니다. 아이콘이 회색이면 확장 프로그램이 해당 페이지를 호환 가능한 양식으로 인식하지 못한 것입니다. 아이콘을 마우스 오른쪽 버튼으로 클릭하고 "이 사이트에서 활성화"를 선택하여 수동으로 활성화할 수 있습니다. 그래도 작동하지 않으면 iframe이나 Java 애플릿과 같은 지원되지 않는 기술을 사용하는 것일 수 있습니다.

실수로 환자 프로필을 삭제했습니다. 복구할 수 있나요?

죄송합니다. 삭제된 프로필은 MedAutoFill 내에서 복구할 수 없습니다. 모든 데이터가 클라우드 백업 없이 로컬로 저장되기 때문입니다. 설정 패널의 "프로필 내보내기" 기능을 사용하여 정기적으로 프로필을 JSON 파일로 내보내고 나중에 다시 가져올 수 있도록 권장합니다.

MedAutoFill이 특정 필드에 잘못된 데이터를 입력합니다. 어떻게 수정하나요?

이는 일반적으로 스마트 필드 감지가 필드를 잘못 식별할 때 발생합니다. MedAutoFill 패널을 열고 "필드 매핑"으로 이동하여 문제가 있는 필드를 찾으세요. 환자 프로필의 올바른 데이터 포인트로 다시 할당하세요. 또는 해당 양식의 모든 필드 매핑을 지우고 "양식 학습 초기화"를 선택하여 처음부터 다시 시작할 수 있습니다.

MedAutoFill은 오프라인에서도 작동하나요?

MedAutoFill은 규칙 기반 입력과 저장된 환자 프로필에 대해 오프라인에서 작동합니다. BYOK AI 기능은 AI 제공자와 통신하기 위해 인터넷 연결이 필요합니다. 대부분의 표준 양식은 인터넷 없이도 작업할 수 있습니다. 단, 온라인 상태에서 프로필을 로드했는지 확인하세요.
