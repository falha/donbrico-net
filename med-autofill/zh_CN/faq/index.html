MedAutoFill — 常见问题解答

入门指南

如何在浏览器上安装 MedAutoFill？

MedAutoFill 是一款 Chrome 扩展程序。请访问 Chrome 网上应用店，搜索"MedAutoFill by Donbrico"，然后点击"添加到 Chrome"。安装完成后，浏览器工具栏中会出现 MedAutoFill 图标，您可以打开设置指南开始创建第一个患者档案。

首次安装 MedAutoFill 后需要做什么？

安装后，打开 MedAutoFill 扩展面板，点击"新建档案"输入第一位患者的人口统计数据、保险详情和医疗服务提供者信息。您还可以配置 BYOK（自带密钥）AI 设置以处理复杂字段。无需注册账户——您的数据从一开始就保存在本地。

MedAutoFill 是否适用于我特定的 EHR 或保险门户？

MedAutoFill 旨在兼容多种 EHR 系统、保险门户和医疗办公软件。如果遇到无法识别的表单或字段，您可以使用"智能字段检测"训练工具教导它识别新布局。大多数用户发现它开箱即用，适用于 Epic、Cerner 和 Practice Fusion 等主流平台。

我能立即使用 MedAutoFill 吗，还是需要学习过程？

您可以在几分钟内开始自动填写表单。该扩展程序附带预配置模板，涵盖患者姓名、出生日期和保险 ID 等常见字段。学习曲线极小——大多数行政人员在填写前两三个测试表单后即可熟练使用。

功能与使用

MedAutoFill 如何处理复杂或非标准表单字段？

MedAutoFill 采用两层架构：基于规则的引擎处理标准字段（姓名、出生日期、保险 ID），BYOK AI 层处理复杂字段如"主诉"或"预授权备注"。您可以连接自己的 OpenAI API 密钥启用 AI 驱动的建议，或使用内置字段检测进行手动数据输入。

我可以在 MedAutoFill 中保存多个患者档案吗？

可以，MedAutoFill 支持多个患者档案。您可以通过扩展面板创建、编辑和切换档案。这对于每天处理数十名患者的医疗账单员和编码员特别有用——只需在自动填写表单前选择正确的档案即可。

智能字段检测功能如何工作？

当您点击表单字段时，MedAutoFill 会扫描页面上的标签、占位符文本和附近的 HTML 元素，以识别该字段要求的内容（例如"保险组号"或"转诊提供者 NPI"）。然后将该字段映射到所选患者档案中的正确数据。如果字段未被识别，您可以手动分配一次，MedAutoFill 会记住该映射用于未来的表单。

MedAutoFill 是否适用于多页表单和向导？

是的，MedAutoFill 专为处理多页表单和分步向导而设计。当您进入下一页时，扩展程序会自动检测并根据当前活跃的患者档案填写相关字段。您无需重新选择档案或重新触发填写。

我可以同时使用 MedAutoFill 填写患者人口统计数据和临床字段吗？

当然可以。MedAutoFill 覆盖患者人口统计数据（姓名、地址、联系方式）、保险信息（保险公司、保单号、组号）、医疗服务提供者详情（NPI、分类代码、转诊医生）以及临床字段（诊断代码、主诉、用药清单）。您可以为每个档案自定义要包含的字段。

隐私与安全

使用 MedAutoFill 时，我的患者数据存储在哪里？

您在 MedAutoFill 中输入的所有患者数据都使用浏览器存储本地保存在您的设备上。没有任何数据上传到 Donbrico 的服务器或任何第三方云端。除非您明确连接 BYOK AI 服务，否则您的数据永远不会离开您的计算机。

MedAutoFill 是否符合 HIPAA 标准？

MedAutoFill 采用隐私优先架构设计，支持 HIPAA 合规性。由于所有数据都保存在本地设备上，因此不会有数据传送到 Donbrico 的服务器。对于 BYOK AI 功能，您控制 API 密钥，并可以选择符合 HIPAA 标准的提供商，如 OpenAI 的企业版。我们建议您咨询所在组织的合规官以确定具体工作流程。

如果我使用 BYOK AI 功能，我的数据会被发送到 OpenAI 吗？

当您启用 BYOK AI 并连接自己的 API 密钥时，您正在填写的特定字段（例如临床记录）中的数据会被发送到您配置的 AI 提供商。患者姓名和出生日期等标准字段永远不会发送给 AI。您也可以完全禁用 AI 功能，仅使用 MedAutoFill 的基于规则的填充。

我的雇主或诊所能看到我在 MedAutoFill 中输入的数据吗？

不能。MedAutoFill 将数据存储在浏览器的本地存储中，该存储与其他应用程序和扩展程序隔离。除非您的雇主能直接访问您的设备，否则他们无法访问您的 MedAutoFill 数据。对于共享工作站，我们建议在每次使用后使用"清除档案"选项。

定价与许可

MedAutoFill 是免费使用还是需要付费版本？

MedAutoFill 提供免费版本，支持最多 5 个患者档案和标准字段检测。高级版本解锁无限患者档案、高级字段映射和 BYOK AI 集成。请访问 Donbrico 网站查看当前定价以及诊所或账单团队的批量折扣信息。

我可以在多个设备上或与团队共享一个 MedAutoFill 许可证吗？

许可证与单个 Chrome 配置文件绑定。对于团队使用，每个用户需要自己的许可证。Donbrico 为诊所和账单代理机构提供团队和企业定价——请通过网站联系销售团队获取定制方案。

高级功能有免费试用吗？

是的，MedAutoFill 提供 14 天的高级功能免费试用，包括无限档案和 BYOK AI。开始试用无需信用卡。试用结束后，您可以选择订阅或继续使用免费版本。

故障排除

MedAutoFill 没有填写我表单上的字段——该怎么办？

首先，确保您选择了正确的患者档案。然后，点击未填写的字段，检查是否出现 MedAutoFill 图标。如果没有出现，该字段可能使用了非标准 HTML。使用扩展程序中的"教导字段"选项手动将其映射到正确的数据点。教导一次后，MedAutoFill 会记住该表单的映射。

扩展程序图标在某些网站上呈灰色——为什么？

MedAutoFill 设计为仅在医疗和健康表单页面上激活。如果图标呈灰色，说明扩展程序未将该页面识别为兼容表单。您可以右键单击图标并选择"在此网站上启用"来手动激活。如果该网站仍然无法使用，可能使用了 iframe 或 Java 小程序等不支持的技术。

我不小心删除了一个患者档案——能恢复吗？

很遗憾，已删除的档案无法在 MedAutoFill 中恢复，因为所有数据都存储在本地，没有云端备份。我们建议您定期使用设置面板中的"导出档案"功能导出档案，将其保存为 JSON 文件，以便日后重新导入。

MedAutoFill 向某些字段填充了错误的数据——如何修复？

这通常是由于智能字段检测错误识别了字段。打开 MedAutoFill 面板，导航到"字段映射"，找到有问题的字段。将其重新分配到患者档案中的正确数据点。或者，您可以清除该表单的所有字段映射，选择"重置表单训练"重新开始。

MedAutoFill 可以离线使用吗？

MedAutoFill 在离线状态下可用于基于规则的填充和已存储的患者档案。BYOK AI 功能需要互联网连接才能与 AI 提供商通信。对于大多数标准表单，您无需互联网即可使用——只需确保在联网时已加载您的档案。
