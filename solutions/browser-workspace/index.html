Frequently Asked Questions

Does it restore Chrome tab groups?

Yes. WorkDesk fully supports Chrome tab groups. When you restore a workspace, your groups are recreated exactly as you left them — same colours, same names.

What happens if my browser crashes before I save?

WorkDesk saves workspaces to Chrome's local storage when you explicitly save. If you haven't saved a session yet, it won't be there after a crash. Use the auto-save reminder feature (Pro) to avoid this.

Can I use it across multiple computers?

Pro users can export workspaces as JSON and import them on another device. Full cloud sync is on the roadmap.

How is this different from Chrome's built-in session restore?

Chrome session restore only returns the last session. WorkDesk lets you save unlimited named workspaces, switch between them on demand, search them by description, and restore any historical session.

Is my browsing data private?

All workspace data is stored locally on your device. Tab URLs and titles may be sent to your AI provider (for naming and search features) if you use a BYOK key. With Gemini Nano (Chrome), everything stays on-device.
