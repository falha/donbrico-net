HostReply AI — 자주 묻는 질문

시작하기

HostReply AI Chrome 확장 프로그램은 어떻게 설치하나요?

donbrico.net/hostreply-ai 제품 페이지를 방문하여 Chrome 웹 스토어 다운로드 링크를 따라가세요. "Chrome에 추가"를 클릭하고 설치를 확인합니다. 설치가 완료되면 브라우저 툴바에 HostReply AI 아이콘이 나타나며, Airbnb, Vrbo, Booking.com에서 바로 사용할 수 있습니다.

HostReply AI를 사용하려면 계정을 만들어야 하나요?

계정을 만들 필요가 없습니다. HostReply AI는 설치 후 브라우저에서 바로 작동합니다. 확장 프로그램이 모든 것을 로컬에서 처리하므로 로그인이나 가입 절차가 없습니다. 그저 설치하고 선호하는 플랫폼에서 게스트 메시지 스레드를 열면 바로 사용할 수 있습니다.

HostReply AI로 첫 게스트 답변을 어떻게 생성하나요?

Airbnb, Vrbo 또는 Booking.com에서 게스트 대화를 열고, 브라우저 툴바에 있는 HostReply AI 아이콘 또는 메시지 입력창 근처에 나타나는 인라인 버튼을 클릭하세요. 확장 프로그램이 대화 내역을 분석하여 상황에 맞는 답변을 생성합니다. 팝업 창에서 검토, 수정 후 바로 전송할 수 있습니다.

데스크탑과 노트북에서 모두 HostReply AI를 사용할 수 있나요?

네, Chrome 확장 프로그램인 HostReply AI는 동일한 Chrome 브라우저에 로그인된 모든 기기에서 동기화됩니다. 각 기기에 한 번씩 설치하면 Chrome 동기화가 활성화된 경우 설정, 템플릿 및 음성 선호도가 자동으로 전송됩니다.

기능 및 사용법

HostReply AI는 어떻게 저처럼 말하는 답변을 생성하나요?

확장 프로그램이 플랫폼에서의 대화 내역을 통해 사용자의 글쓰기 스타일을 학습합니다. 과거 메시지를 분석하여 어조, 격식 수준 및 표현 방식의 패턴을 감지합니다. 설정 패널에서 맞춤 음성 선호도를 설정하여 캐주얼 또는 전문적인 특정 언어 스타일을 강화할 수도 있습니다.

HostReply AI가 체크인 및 체크아웃 메시지를 자동으로 처리할 수 있나요?

네, HostReply AI에는 체크인 안내, 체크아웃 알림 및 기타 일반적인 시나리오를 위한 빠른 템플릿이 포함되어 있습니다. 확장 프로그램 팝업에서 한 번 클릭으로 이 템플릿을 활성화할 수 있습니다. 각 템플릿은 대화 맥락에서 관련 예약 정보를 자동으로 가져오므로 날짜나 게스트 이름을 수동으로 입력할 필요가 없습니다.

HostReply AI는 Airbnb에서만 작동하나요, 아니면 Vrbo와 Booking.com에서도 작동하나요?

HostReply AI는 Airbnb, Vrbo, Booking.com의 세 가지 주요 플랫폼을 모두 지원하도록 설계되었습니다. 이 사이트 중 하나에서 메시지 스레드를 열면 확장 프로그램이 플랫폼을 감지하고 인터페이스와 일반적인 메시지 구조에 맞게 답변 생성을 조정합니다.

HostReply AI의 빠른 템플릿을 어떻게 사용자 지정하나요?

HostReply AI 아이콘을 마우스 오른쪽 버튼으로 클릭하고 "옵션"을 선택하여 확장 프로그램 설정을 엽니다. 여기에서 체크인, 체크아웃, 늦은 도착 및 기타 일반적인 답변에 대한 기본 템플릿을 편집할 수 있습니다. 또한 처음부터 새 템플릿을 만들고 특정 트리거 단어나 예약 상태에 할당할 수도 있습니다.

HostReply AI가 게스트 메시지를 번역해 주나요?

HostReply AI는 게스트가 보낸 메시지와 동일한 언어로 답변을 생성할 수 있습니다. 게스트가 프랑스어로 작성하면 제안된 답변도 프랑스어로 제공됩니다. 로컬 AI 모델이 완전히 지원하지 않는 언어의 경우, 확장 프로그램이 전송 전에 번역을 확인하도록 안내합니다.

개인정보 보호 및 보안

게스트 대화 데이터는 어디에 저장되나요?

모든 데이터 처리는 사용자 컴퓨터에서 로컬로 이루어집니다. HostReply AI는 게스트 대화, 예약 세부 정보 또는 개인 정보를 외부 서버로 전송하지 않습니다. 확장 프로그램은 브라우저 내에서 완전히 실행되는 로컬 AI 모델을 사용하므로 데이터가 기기를 벗어나지 않습니다.

HostReply AI가 제 호스팅 데이터를 제3자와 공유하나요?

아니요. HostReply AI는 개인정보 보호를 최우선으로 설계된 도구입니다. 제3자 분석, 메시지 클라우드 저장, 광고주 또는 플랫폼 제공업체와의 데이터 공유가 전혀 없습니다. 전송되는 유일한 데이터는 모든 Chrome 확장 프로그램에 표준적인 확장 프로그램 업데이트 확인입니다.

부동산 관리팀이 게스트 데이터를 서로 노출하지 않고 HostReply AI를 사용할 수 있나요?

네. 모든 처리가 각 사용자의 브라우저에서 로컬로 이루어지기 때문에 팀원들은 게스트 데이터를 중앙화하지 않고 자신의 기기에 HostReply AI를 설치할 수 있습니다. 각 호스트나 관리자는 자신의 대화를 완전히 제어하며, 팀 전체의 메시지 기록을 저장하는 공유 서버는 없습니다.

확장 프로그램을 제거하면 내 데이터는 어떻게 되나요?

HostReply AI를 제거하면 확장 프로그램과 로컬 데이터가 브라우저에서 삭제됩니다. 저장된 템플릿이나 음성 선호도도 확장 프로그램과 함께 삭제됩니다. Airbnb, Vrbo 또는 Booking.com의 게스트 대화는 영향을 받지 않으며 해당 플랫폼에 그대로 유지됩니다.

가격 및 라이선스

HostReply AI의 무료 버전이 있나요? 어떤 기능이 포함되나요?

네, HostReply AI는 기본 답변 생성과 표준 빠른 템플릿 이용이 가능한 무료 티어를 제공합니다. 무료 버전은 하루에 생성할 수 있는 답변 수에 제한이 있습니다. 무제한 사용과 맞춤 음성 학습 및 템플릿 생성 같은 고급 기능을 이용하려면 프리미엄 라이선스가 필요합니다.

프리미엄 버전 가격은 얼마이며, 어떻게 결제하나요?

HostReply AI의 가격은 donbrico.net/hostreply-ai 제품 페이지에 명시되어 있습니다. 프리미엄 라이선스는 현재 플랜에 따라 일회성 구매 또는 구독 형태로 제공됩니다. 결제는 Chrome 웹 스토어 또는 Donbrico 체크아웃 페이지를 통해 안전하게 처리되며, 언제든지 무료 버전에서 업그레이드할 수 있습니다.

HostReply AI가 제 숙소에 맞지 않으면 환불받을 수 있나요?

환불 정책은 라이선스를 구매한 플랫폼(Chrome 웹 스토어 또는 Donbrico 직접 구매)에서 처리합니다. 구매 시점의 특정 환불 약관을 확인하세요. 대부분의 디지털 제품은 확장 프로그램이 설명된 대로 작동하지 않는 경우 30일 환불 기간을 제공합니다.

문제 해결

HostReply AI가 Airbnb 메시지 페이지에 나타나지 않는 이유는 무엇인가요?

먼저 Chrome에서 chrome://extensions로 이동하여 HostReply AI가 활성화되어 있는지 확인하세요. 그래도 나타나지 않으면 Airbnb 탭을 새로고침하거나 Chrome을 다시 시작해 보세요. 일부 광고 차단기나 개인정보 보호 확장 프로그램이 간섭할 수 있으니, 임시로 비활성화하고 테스트해 보세요.

HostReply AI가 제 호스팅 스타일과 맞지 않는 답변을 생성합니다. 어떻게 해결하나요?

확장 프로그램 설정을 열고 음성 선호도 설정을 확인하세요. 맞춤 음성을 설정하지 않은 경우, 확장 프로그램은 기본적으로 대화 내역을 사용하며, 몇 개의 메시지로 보정하는 데 시간이 걸릴 수 있습니다. 먼저 5-10개의 수동 답변을 보내 로컬 AI가 학습할 데이터를 더 제공한 후 다시 생성해 보세요.

확장 프로그램이 느리게 실행되거나 멈춥니다. 어떻게 해야 하나요?

HostReply AI는 로컬 AI 모델을 실행하므로 구형 컴퓨터에서 리소스를 많이 사용할 수 있습니다. 다른 무거운 브라우저 탭이나 애플리케이션을 닫아 메모리를 확보하세요. 문제가 지속되면 chrome://extensions로 이동하여 HostReply AI를 비활성화한 후 다시 활성화하고 Chrome을 재시작하세요. 지속적인 성능 문제가 있으면 제품 페이지에서 알려진 문제나 업데이트를 확인하세요.

공유 컴퓨터나 업무용 컴퓨터에서 HostReply AI를 사용할 수 있나요?

네, 하지만 로컬 AI 모델과 저장된 템플릿은 해당 특정 Chrome 프로필에 저장된다는 점을 유의하세요. 같은 컴퓨터에서 다른 Chrome 계정으로 로그인하면 HostReply AI를 다시 설치하고 설정해야 합니다. 공유 컴퓨터의 경우 Chrome에서 로그아웃하여 호스팅 데이터를 보호하세요.
