Donbrico Autofill AI Support

Common Issues

The extension button isn't appearing on a form

Some websites use JavaScript to render forms dynamically. Try scrolling down to trigger the page to fully load, then look for the ⚡ button. If it still doesn't appear, email us with the URL of the site.

Gemini Nano says "Not supported on this device"

Gemini Nano requires Chrome 127+ and sufficient device RAM (typically 8GB+). You can still use the extension by adding your own API key in Settings (Bring Your Own Key). OpenAI, Anthropic, Groq, and OpenRouter are all supported.

My profile isn't saving

Go to the extension's Options page (right-click extension icon → Options). Make sure you've clicked Save after entering your profile. If it still doesn't save, try the Troubleshoot button on the Options page.

The AI-generated answer doesn't sound like me

The AI uses your profile to generate answers. Fill in the Bio and Experience fields with detail — the more context you give it, the better the output. You can always edit any answer before submitting.

How do I uninstall and remove my data?

In Chrome, go to chrome://extensions, find Donbrico Autofill AI, click Remove. All your profile data will be deleted automatically.

How do I report a bug or request a feature?

Email support@donbrico.net with "Bug:" or "Feature Request:" at the start of your subject line.

Donbrico HostReply AI Support

Common Issues

The extension toolbar isn't appearing on Airbnb or Vrbo

Make sure you're on the messaging inbox page. Refresh the page if the toolbar doesn't appear.

Host Memory details aren't being used in replies

Check that you've saved your property details in the Host Memory tab of the extension popup.

Donbrico AI Reply Assistant Support

Common Issues

The extension toolbar isn't appearing on a page

Make sure you're on a page with a text field (input or textarea). Click inside the field first — the AI Reply toolbar should appear near the field. If it doesn't, refresh the page and try again.

My saved replies aren't showing up

Check that you've saved replies in the Library tab of the extension popup. If you recently re-installed, replies stored locally are gone unless you exported a backup (Pro feature).

Gemini Nano says "Not supported on this device"

Gemini Nano requires Chrome 127+ with sufficient RAM (typically 8GB+). You can still use the extension by adding your own API key in Settings (Bring Your Own Key). Supported providers: OpenAI, Anthropic, Groq, OpenRouter.

AI-generated replies sound generic or off-topic

The AI uses the text field's context plus your selected tone. For best results, use specific prompts and set a detailed tone. If using a BYOK provider, try switching to a different model.

How do I uninstall and remove my data?

In Chrome, go to chrome://extensions, find Donbrico AI Reply Assistant, click Remove. This deletes all locally stored replies and settings.

How do I report a bug or request a feature?

Email support@donbrico.net with "Bug:" or "Feature Request:" at the start of your subject line.

Donbrico WorkDesk Support

Common Issues

How do I save a workspace?

Click the extension icon to open the popup, then click 'Save Current window' or 'Save All Windows'. AI will suggest a name, or you can type your own.

Can I restore workspaces on another computer?

Yes, if you use the 'Export as JSON' feature (Pro) to backup your data and import it on your other device.

What happens if I delete a workspace?

Deleted workspaces are gone forever. However, you can use the 'Archive' feature to hide workspaces without deleting them.

FileWhisperer AI Support

Common Issues

Why does the model download take so long?

On the first run, FileWhisperer AI downloads highly-optimized Llama-3 models (~2-4GB) to run completely offline. Depending on your internet speed, this might take several minutes, but once downloaded, you'll never need an internet connection again.

What file types are supported?

Currently, FileWhisperer AI supports PDF documents (.pdf), rich text (.rtf), Word documents (.docx), text files (.txt), markdown (.md), and Excel/CSV spreadsheets.

ReceiptWhisperer AI Support

Common Issues

The OCR engine skipped some items on my receipt

Extremely blurry scans, crumpled paper, or handwriting can lower OCR accuracy. Try straightening the receipt and scanning under good lighting. You can always manually double-click any parsed field to edit values directly.

How do I backup my expense data?

Go to Settings in the application and click 'Export Expense Vault'. This exports a self-contained database backup (.db) along with all categorized receipt images in a single ZIP archive.

MeetingWhisperer AI Support

Common Issues

My video file is taking too long to transcribe

High-definition video files can take longer to load. MeetingWhisperer AI automatically extracts the audio track first to save resources. Check your system's hardware acceleration in Settings — selecting CUDA (NVIDIA) or DirectML can speed up Whisper by up to 5x.

How do I improve speaker identification?

Local speaker diarization works best when speakers do not overlap or interrupt frequently. You can name detected speaker profiles (e.g. 'Speaker 1' -> 'Alice') in the audio transcript editor to update the names globally.
