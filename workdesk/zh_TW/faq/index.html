WorkDesk — 常見問題解答

入門指南

如何在 Chrome 瀏覽器安裝 WorkDesk？

直接從 Chrome 線上應用程式商店搜尋「WorkDesk」，或前往產品頁面 donbrico.net/workdesk 進行安裝。點擊「加到 Chrome」並確認安裝。安裝完成後，您會在瀏覽器工具列看到 WorkDesk 圖示。

第一次開啟 WorkDesk 會發生什麼事？

安裝後，點擊 WorkDesk 圖示開啟控制面板。您會看到將目前瀏覽器視窗儲存為第一個工作區的選項。WorkDesk 會自動偵測所有開啟的分頁與分頁群組，讓您無需任何設定即可立即命名並儲存工作區。

使用 WorkDesk 需要建立帳戶嗎？

不需要帳戶或註冊。WorkDesk 設計為完全離線運作，並在您的本機裝置上執行。所有工作區資料都儲存在瀏覽器的本地儲存空間中，因此安裝後即可立即開始儲存與還原工作區。

如何儲存我的第一個工作區？

點擊工具列圖示開啟 WorkDesk 彈出視窗，然後按一下「儲存目前工作區」按鈕。為工作區命名，例如「研究專案」或「開發衝刺」，WorkDesk 會捕捉所有開啟的分頁及其分頁群組設定。您也可以加入描述，方便日後辨識工作區。

功能與使用

我可以使用 WorkDesk 儲存與還原分頁群組嗎？

可以，WorkDesk 完全支援 Chrome 分頁群組。當您儲存工作區時，所有現有的分頁群組（包含名稱與顏色）都會被保留。稍後還原該工作區時，分頁群組會完全依照您離開時的狀態重現，省去手動重新整理分頁的麻煩。

如何在關閉目前分頁的情況下切換不同工作區？

點擊 WorkDesk 圖示，選取要切換的工作區。WorkDesk 會在背景儲存您目前的分頁，並立即還原新工作區。先前的工作區會保留，因此您可以隨時切換回來，不會遺失當前上下文，也無需為所有分頁建立書籤。

我可以依專案或主題整理工作區嗎？

當然可以。WorkDesk 讓您為每個工作區命名，並加入選擇性描述。您也可以在工作區控制面板中拖曳重新排序。這讓您能輕鬆依專案、客戶、研究主題或任何符合工作流程的方式來分組工作區。

WorkDesk 支援固定分頁與多個視窗嗎？

支援，WorkDesk 會捕捉固定分頁，並在還原時保留其固定狀態。它也支援單一工作區內的多個 Chrome 視窗。如果分頁分散在多個視窗中，WorkDesk 會儲存並還原所有分頁，同時保持視窗結構完整。

我可以與同事或跨裝置分享工作區嗎？

WorkDesk 將所有資料儲存在本機，不包含雲端同步或分享功能。這是基於保護隱私的設計原則。如果您需要分享工作區，可以手動匯出分頁或建立書籤，但 WorkDesk 本身專注於個人本機工作區管理。

隱私與安全

我的工作區資料儲存在哪裡？

所有工作區資料完全儲存在瀏覽器的本地儲存空間中。WorkDesk 不會將任何資料傳送到外部伺服器、雲端服務或第三方。您的分頁、URL 與分頁群組資訊絕不會離開您的電腦。

WorkDesk 會收集或販售我的瀏覽資料嗎？

不會。WorkDesk 是隱私優先的擴充功能，不會收集任何分析資料、遙測數據或個人資訊。沒有追蹤器、使用記錄或資料分享。該擴充功能完全離線運作，僅具備讀取目前分頁所需的網路權限。

WorkDesk 會使用 AI 或處理我的分頁內容嗎？

WorkDesk 不使用 AI、機器學習或任何形式的內容處理。它僅讀取開啟分頁的 URL 與分頁群組中繼資料，以便儲存與還原工作區。它不會讀取頁面內容、追蹤您的活動或分析您的瀏覽行為。

WorkDesk 對敏感或機密分頁安全嗎？

是的。由於 WorkDesk 將所有資料儲存在本機且不傳輸至任何地方，因此對機密工作安全無虞。無論您是在研究法律案件、管理財務資料或處理機密客戶資訊，您的分頁都將在您自己的電腦上保持隱私。

價格與授權

WorkDesk 免費使用嗎？

WorkDesk 提供免費方案，包含儲存與還原工作區等核心功能。未來可能會有進階功能或使用限制，但目前版本對大多數使用者而言功能完整。請前往產品頁面 donbrico.net/workdesk 查看最新價格詳情。

進階版本包含哪些內容？

如果提供進階版本，通常包含無限工作區儲存空間、進階整理功能與優先支援。免費版本設計為完全可用於日常工作區管理，不會強迫您升級付費方案。

如何支付 WorkDesk？有訂閱制嗎？

付款與訂閱詳細資訊請見 WorkDesk 產品頁面。WorkDesk 可能提供一次性購買或訂閱模式。未經您同意不會自動扣款，若適用訂閱方案，您可隨時取消。

疑難排解

WorkDesk 無法儲存所有分頁，該檢查什麼？

首先，確認您已授予 WorkDesk 讀取分頁的必要權限。您可以在 Chrome 擴充功能設定的「網站存取權」中檢查。此外，請確認您沒有開啟特殊的 Chrome 頁面（如 chrome://settings 或 chrome://extensions），因為這些頁面無法儲存。如果問題持續，請重新啟動 Chrome 再試一次。

我還原了工作區，但有些分頁沒有載入，為什麼？

這通常是因為分頁已無法使用（例如頁面已刪除或連結失效）。WorkDesk 會儲存您開啟的 URL，但無法保證這些頁面仍然存在。此外，如果您啟用了 Chrome 的「繼續瀏覽上次開啟的網頁」設定，可能會干擾 WorkDesk 的還原功能。請嘗試在 Chrome 的啟動選項中停用該設定。

如何解除安裝 WorkDesk 而不遺失工作區？

解除安裝前，請開啟 WorkDesk 手動記錄或匯出您的工作區名稱與 URL，因為解除安裝擴充功能會刪除所有本地儲存資料。若要解除安裝，請右鍵點擊 WorkDesk 圖示，選取「從 Chrome 移除」並確認。工作區將會遺失，因此請先備份重要資料。

WorkDesk 似乎很慢或沒有回應，如何解決？

嘗試關閉不必要的分頁並重新啟動 Chrome。WorkDesk 本身輕量，但如果單一工作區包含數百個分頁，效能可能會下降。您也可以從控制面板移除未使用的工作區，以減少 WorkDesk 需管理的資料量。如果問題持續，請從 Chrome 線上應用程式商店重新安裝擴充功能。
