WorkDesk — 常见问题解答

快速入门

如何在 Chrome 浏览器中安装 WorkDesk？

直接从 Chrome 网上应用店安装 WorkDesk，搜索 "WorkDesk" 或访问产品页面 donbrico.net/workdesk。点击"添加至 Chrome"并确认安装。安装后，您将在浏览器工具栏中看到 WorkDesk 图标。

首次打开 WorkDesk 时会发生什么？

安装后，点击 WorkDesk 图标打开控制面板。您会看到将当前浏览器窗口保存为第一个工作区的选项。WorkDesk 会自动检测所有打开的标签页和标签页分组，因此您可以立即命名并保存工作区，无需任何配置。

使用 WorkDesk 需要创建账户吗？

无需账户或注册。WorkDesk 设计为完全离线运行，数据存储在本地计算机上。所有工作区数据都保存在浏览器的本地存储中，安装后即可开始保存和恢复工作区。

如何保存我的第一个工作区？

点击工具栏图标打开 WorkDesk 弹出窗口，然后点击"保存当前工作区"按钮。为工作区命名，例如"研究项目"或"开发冲刺"，WorkDesk 将捕获所有打开的标签页及其分组分配。您还可以添加描述，以便日后识别该工作区。

功能与使用

我可以用 WorkDesk 保存和恢复标签页分组吗？

可以，WorkDesk 完全支持 Chrome 标签页分组。保存工作区时，所有现有标签页分组（包括名称和颜色）都会被保留。稍后恢复该工作区时，标签页分组将完全按照您离开时的状态重现，无需手动重新整理标签页。

如何在不关闭当前标签页的情况下切换不同工作区？

点击 WorkDesk 图标，选择要切换的工作区。WorkDesk 会在后台保存当前标签页，并立即恢复新工作区。您之前的工作区仍会保存，因此可以随时切换回来，无需丢失上下文或为所有页面添加书签。

我可以按项目或主题整理工作区吗？

当然可以。WorkDesk 允许您为每个工作区命名，并添加可选描述。您还可以在控制面板中通过拖拽重新排列工作区。这使您能够轻松按项目、客户、研究主题或任何适合您工作流程的方式对工作区进行分组。

WorkDesk 支持固定标签页和多个窗口吗？

支持。WorkDesk 会捕获固定标签页，并在恢复时保留其固定状态。它还支持单个工作区中的多个 Chrome 窗口。如果您的标签页分布在多个窗口中，WorkDesk 将全部保存和恢复，并保持窗口结构完整。

我可以与同事或跨设备共享工作区吗？

WorkDesk 将所有数据存储在本地计算机上，不包含云同步或共享功能。这是出于保护隐私的设计考虑。如果您需要共享工作区，可以手动导出标签页或为其添加书签，但 WorkDesk 本身专注于个人本地工作区管理。

隐私与安全

我的工作区数据存储在哪里？

所有工作区数据完全存储在浏览器的本地存储中。WorkDesk 不会将任何数据发送到外部服务器、云服务或第三方。您的标签页、URL 和标签页分组信息永远不会离开您的计算机。

WorkDesk 会收集或出售我的浏览数据吗？

不会。WorkDesk 是一款隐私优先的扩展，不收集任何分析数据、遥测数据或个人数据。没有跟踪器、使用日志或数据共享。该扩展完全离线运行，除读取当前标签页所需的权限外，没有其他网络权限。

WorkDesk 使用 AI 或处理我的标签页内容吗？

WorkDesk 不使用 AI、机器学习或任何形式的内容处理。它仅读取您打开标签页的 URL 和标签页分组元数据，以保存和恢复工作区。它不会读取页面内容、跟踪您的活动或分析您的浏览行为。

WorkDesk 在处理敏感或机密标签页时安全吗？

安全。由于 WorkDesk 将所有数据存储在本地且不传输任何数据，因此适用于敏感工作。无论您是在研究法律案件、管理财务数据还是处理机密客户信息，您的标签页都保留在您自己的计算机上，保持私密。

定价与许可

WorkDesk 免费使用吗？

WorkDesk 提供免费版本，包含保存和恢复工作区等核心功能。未来可能会推出高级功能或使用限制，但当前版本对大多数用户来说功能齐全。请访问产品页面 donbrico.net/workdesk 了解最新定价详情。

高级版本包含哪些内容？

如果高级版本可用，通常包含无限工作区存储、高级组织功能和优先支持。免费版本设计为完全可用于日常工作区管理，不会强制您升级到付费计划。

如何支付 WorkDesk，是否有订阅？

支付和订阅详情可在 WorkDesk 产品页面上找到。WorkDesk 可能提供一次性购买或订阅模式。未经您的同意不会自动扣费，如果涉及订阅，您可以随时取消。

故障排除

WorkDesk 无法保存所有标签页。我应该检查什么？

首先，确保您已授予 WorkDesk 读取标签页的必要权限。您可以在 Chrome 的扩展设置中的"网站访问权限"下进行检查。另外，请确认您没有打开任何特殊的 Chrome 页面（如 chrome://settings 或 chrome://extensions），因为这些页面无法保存。如果问题仍然存在，请重启 Chrome 并重试。

我恢复了一个工作区，但有些标签页没有加载。为什么？

这通常发生在标签页不再可用时（例如页面已删除或链接失效）。WorkDesk 会保存您打开的 URL，但无法保证这些页面仍然存在。此外，如果您启用了 Chrome 的"继续浏览上次打开的网页"设置，它可能会干扰 WorkDesk 的恢复功能。请尝试在 Chrome 的启动选项中禁用该设置。

如何卸载 WorkDesk 而不丢失工作区？

卸载前，请打开 WorkDesk 手动记录或导出工作区名称和 URL，因为卸载扩展将删除所有本地存储的数据。要卸载，右键单击 WorkDesk 图标，选择"从 Chrome 中移除"，然后确认。您的工作区将丢失，因此请先备份重要内容。

WorkDesk 运行缓慢或没有响应。如何解决？

尝试关闭不必要的标签页并重启 Chrome。WorkDesk 本身很轻量，但如果您单个工作区中有数百个标签页，性能可能会下降。您还可以尝试从控制面板中删除未使用的工作区，以减少 WorkDesk 需要管理的数据量。如果问题持续存在，请从 Chrome 网上应用店重新安装该扩展。
