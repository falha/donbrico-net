WorkDesk — 자주 묻는 질문

시작하기

WorkDesk을 Chrome 브라우저에 어떻게 설치하나요?

Chrome 웹 스토어에서 "WorkDesk"을 검색하거나 donbrico.net/workdesk 제품 페이지를 방문하여 WorkDesk을 직접 설치하세요. "Chrome에 추가"를 클릭하고 설치를 확인하면 됩니다. 설치가 완료되면 브라우저 툴바에 WorkDesk 아이콘이 나타납니다.

WorkDesk을 처음 열면 어떻게 되나요?

설치 후 WorkDesk 아이콘을 클릭하여 대시보드를 엽니다. 현재 브라우저 창을 첫 번째 워크스페이스로 저장할 수 있는 옵션이 표시됩니다. WorkDesk이 열려 있는 모든 탭과 탭 그룹을 자동으로 감지하므로, 별도 설정 없이 바로 워크스페이스 이름을 지정하고 저장할 수 있습니다.

WorkDesk을 사용하려면 계정을 만들어야 하나요?

계정이나 회원가입이 필요하지 않습니다. WorkDesk은 완전히 오프라인에서 로컬 기기에서 작동하도록 설계되었습니다. 모든 워크스페이스 데이터는 브라우저의 로컬 스토리지에 저장되므로, 설치 후 바로 워크스페이스를 저장하고 복원할 수 있습니다.

첫 번째 워크스페이스는 어떻게 저장하나요?

툴바 아이콘을 클릭하여 WorkDesk 팝업을 열고 "현재 워크스페이스 저장" 버튼을 누르세요. "연구 프로젝트"나 "개발 스프린트"처럼 워크스페이스 이름을 지정하면, WorkDesk이 열려 있는 모든 탭과 탭 그룹 할당을 캡처합니다. 설명을 추가하면 나중에 워크스페이스를 더 쉽게 식별할 수 있습니다.

기능 및 사용법

WorkDesk으로 탭 그룹을 저장하고 복원할 수 있나요?

네, WorkDesk은 Chrome 탭 그룹을 완벽하게 지원합니다. 워크스페이스를 저장하면 이름과 색상을 포함한 모든 기존 탭 그룹이 보존됩니다. 나중에 해당 워크스페이스를 복원하면 탭 그룹이 그대로 다시 나타나므로, 탭을 수동으로 재정리할 필요가 없습니다.

현재 탭을 닫지 않고 다른 워크스페이스로 전환하려면 어떻게 하나요?

WorkDesk 아이콘을 클릭하고 전환하려는 워크스페이스를 선택하세요. WorkDesk이 현재 탭을 백그라운드에 저장하고 새 워크스페이스를 즉시 복원합니다. 이전 워크스페이스는 저장된 상태로 유지되므로, 언제든지 다시 전환해도 컨텍스트를 잃거나 모든 것을 북마크할 필요가 없습니다.

프로젝트나 주제별로 워크스페이스를 정리할 수 있나요?

물론입니다. WorkDesk에서는 각 워크스페이스에 이름을 지정하고 선택적으로 설명을 추가할 수 있습니다. 대시보드에서 워크스페이스를 드래그하여 순서를 변경할 수도 있습니다. 프로젝트, 고객, 연구 주제 등 작업 흐름에 맞는 방식으로 워크스페이스를 쉽게 그룹화할 수 있습니다.

WorkDesk은 고정 탭과 여러 창에서도 작동하나요?

네, WorkDesk은 고정 탭을 캡처하고 복원 시 고정 상태를 유지합니다. 또한 단일 워크스페이스 내에서 여러 Chrome 창을 지원합니다. 여러 창에 걸쳐 탭이 분산되어 있어도 WorkDesk이 모두 저장하고 복원하며 창 구조를 그대로 유지합니다.

동료나 다른 기기와 워크스페이스를 공유할 수 있나요?

WorkDesk은 모든 데이터를 로컬 기기에 저장하며 클라우드 동기화나 공유 기능을 포함하지 않습니다. 이는 사용자 프라이버시를 유지하기 위한 설계입니다. 워크스페이스를 공유해야 한다면 수동으로 탭을 내보내거나 북마크할 수 있지만, WorkDesk 자체는 개인 로컬 워크스페이스 관리에 초점을 맞추고 있습니다.

개인정보 보호 및 보안

내 워크스페이스 데이터는 어디에 저장되나요?

모든 워크스페이스 데이터는 브라우저의 로컬 스토리지에 완전히 저장됩니다. WorkDesk은 외부 서버, 클라우드 서비스 또는 제3자에게 데이터를 전송하지 않습니다. 탭, URL, 탭 그룹 정보는 절대 사용자 컴퓨터를 떠나지 않습니다.

WorkDesk이 내 브라우징 데이터를 수집하거나 판매하나요?

아니요. WorkDesk은 프라이버시 우선 확장 프로그램으로, 분석 데이터, 원격 측정 데이터, 개인 데이터를 전혀 수집하지 않습니다. 추적기, 사용 로그, 데이터 공유가 없습니다. 이 확장 프로그램은 완전히 오프라인으로 작동하며, 현재 탭을 읽는 데 필요한 네트워크 권한 외에는 어떠한 권한도 없습니다.

WorkDesk이 AI를 사용하거나 내 탭 내용을 처리하나요?

WorkDesk은 AI, 머신러닝 또는 어떤 형태의 콘텐츠 처리도 사용하지 않습니다. 워크스페이스를 저장하고 복원하기 위해 열려 있는 탭의 URL과 탭 그룹 메타데이터만 읽습니다. 페이지 내용을 읽거나, 활동을 추적하거나, 브라우징 행동을 분석하지 않습니다.

WorkDesk을 민감하거나 기밀 탭과 함께 사용해도 안전한가요?

네. WorkDesk은 모든 것을 로컬에 저장하고 데이터를 어디로도 전송하지 않으므로 민감한 작업에 안전합니다. 법률 사건을 조사하거나, 금융 데이터를 관리하거나, 기밀 고객 정보를 처리하는 경우에도 탭은 사용자 기기에서 비공개로 유지됩니다.

가격 및 라이선스

WorkDesk은 무료인가요?

WorkDesk은 워크스페이스 저장 및 복원과 같은 핵심 기능을 포함한 무료 버전을 제공합니다. 향후 프리미엄 기능이나 사용량 제한이 있을 수 있지만, 현재 버전은 대부분의 사용자에게 완전한 기능을 제공합니다. 최신 가격 정보는 donbrico.net/workdesk 제품 페이지를 확인하세요.

프리미엄 버전에는 무엇이 포함되나요?

프리미엄 버전이 제공되는 경우, 일반적으로 무제한 워크스페이스 저장소, 고급 정리 기능, 우선 지원이 포함됩니다. 무료 버전은 유료 플랜을 강요하지 않으면서 일상적인 워크스페이스 관리에 충분히 사용할 수 있도록 설계되었습니다.

WorkDesk 요금은 어떻게 지불하며, 구독 방식인가요?

결제 및 구독 세부 정보는 WorkDesk 제품 페이지에서 확인할 수 있습니다. WorkDesk은 일회성 구매 또는 구독 모델을 제공할 수 있습니다. 동의 없이 자동 청구되지 않으며, 구독이 적용되는 경우 언제든지 취소할 수 있습니다.

문제 해결

WorkDesk이 모든 탭을 저장하지 않습니다. 무엇을 확인해야 하나요?

먼저 WorkDesk에 탭을 읽을 수 있는 필요한 권한을 부여했는지 확인하세요. Chrome 확장 프로그램 설정의 "사이트 액세스"에서 확인할 수 있습니다. 또한 chrome://settings나 chrome://extensions 같은 특수 Chrome 페이지는 저장할 수 없으므로 열려 있지 않은지 확인하세요. 문제가 지속되면 Chrome을 다시 시작하고 다시 시도해 보세요.

워크스페이스를 복원했는데 일부 탭이 로드되지 않았습니다. 왜 그런가요?

이는 일반적으로 탭을 더 이상 사용할 수 없는 경우(예: 삭제된 페이지나 깨진 링크) 발생합니다. WorkDesk은 열려 있던 URL을 저장하지만, 해당 페이지가 여전히 존재한다는 것을 보장할 수 없습니다. 또한 Chrome의 "중단한 위치에서 계속하기" 설정이 활성화되어 있으면 WorkDesk 복원을 방해할 수 있습니다. Chrome 시작 옵션에서 해당 설정을 비활성화해 보세요.

워크스페이스를 잃지 않고 WorkDesk을 제거하려면 어떻게 하나요?

제거하기 전에 WorkDesk을 열고 워크스페이스 이름과 URL을 수동으로 기록하거나 내보내세요. 확장 프로그램을 제거하면 모든 로컬 저장 데이터가 삭제됩니다. 제거하려면 WorkDesk 아이콘을 마우스 오른쪽 버튼으로 클릭하고 "Chrome에서 제거"를 선택한 후 확인하세요. 워크스페이스가 손실되므로 중요한 것은 먼저 백업하세요.

WorkDesk이 느리거나 응답하지 않습니다. 어떻게 해결하나요?

불필요한 탭을 닫고 Chrome을 다시 시작해 보세요. WorkDesk은 가볍지만, 단일 워크스페이스에 수백 개의 탭이 있으면 성능이 저하될 수 있습니다. 대시보드에서 사용하지 않는 워크스페이스를 제거하여 WorkDesk이 관리해야 하는 데이터를 줄일 수도 있습니다. 문제가 지속되면 Chrome 웹 스토어에서 확장 프로그램을 다시 설치하세요.
