TradeDesk AI — Frequently Asked Questions

Getting Started

How do I install TradeDesk AI on my browser?

Install TradeDesk AI directly from the Chrome Web Store or your browser's extension marketplace. After adding it, you'll see the TradeDesk icon appear in your browser toolbar — click it to open the setup panel where you'll enter your API key and configure your business profile.

What do I need to start using TradeDesk AI?

You need three things: a supported browser (Chrome, Edge, or Firefox), an API key from a provider like OpenAI, Groq, or Anthropic, and your basic business details. Once you enter your API key in the extension settings, you can start generating replies immediately — no account registration or credit card required for the free plan.

Do I need to create an account on Donbrico to use the extension?

No account is required. TradeDesk AI runs entirely through your browser extension using your own API key. There's no cloud login, no password to remember, and no user database — just install, configure, and start drafting.

How do I set up my business profile for the first time?

Open the extension panel and navigate to the "Business Profile" section. Fill in your company name, phone number, email, license number, and service area. Once saved, TradeDesk AI will auto-fill these details into every reply, quote, and estimate you generate — saving you from typing the same information repeatedly.

Features & Usage

How do I use TradeDesk AI inside Gmail or Outlook?

Compose a new email or reply to an existing thread, then click the TradeDesk AI icon that appears inside the email window. Select a scenario (like "Quote Request" or "Follow-Up"), add your rough notes, and click Generate — the extension will insert a polished reply directly into your message body.

What are the 23+ built-in scenarios, and how do I pick the right one?

Scenarios cover common contractor communications: quote estimates, permit follow-ups, job confirmations, change orders, warranty reminders, and more. When you open the scenario menu, each option includes a short description. If you're unsure, start with "Quick Reply" — it adapts to whatever notes you provide.

Can TradeDesk AI generate quotes and estimates, or just email replies?

It handles both. Select a scenario like "Formal Estimate" or "Material Quote," enter the job details and pricing, and TradeDesk AI will format everything into a professional document. The output works in any web form, so you can paste it into your CRM, invoicing tool, or customer portal.

How does the trade specialization work for HVAC, plumbing, or electrical work?

In the extension settings, select your primary trade from the list of 8 options — HVAC, plumbing, electrical, roofing, landscaping, handyman, painting, or general contracting. TradeDesk AI then uses industry-specific terminology for that trade when generating replies, so a plumber gets "water heater" and "drain line" while an electrician gets "breaker panel" and "conduit."

Can I save my own templates and reuse them later?

Yes, the free plan includes 5 saved template slots. After generating a reply you like, click "Save as Template" and give it a name. You can load that template in future sessions and regenerate it with updated details — useful for recurring jobs or seasonal promotions.

Privacy & Security

Where is my data processed when I use TradeDesk AI?

All data processing happens through your chosen AI provider's API — TradeDesk AI itself has no backend servers. The extension sends your notes directly from your browser to the API endpoint you configure (OpenAI, Groq, Anthropic, etc.), and the generated reply comes back to your browser. Nothing is stored or logged on Donbrico's infrastructure.

Does TradeDesk AI store my emails or customer information?

No. TradeDesk AI reads the email thread you're currently viewing only to provide context for the AI generation. It does not save, cache, or transmit your emails, customer names, addresses, or any other personal data to any server outside of the API call you authorize.

Is it safe to use my own API key with this extension?

Yes, and it's the most secure approach. Your API key is stored locally in your browser's extension storage, not on any remote server. When you generate a reply, the key is passed directly to the API provider — the same way any app using API keys works. You can revoke or rotate the key at any time from your provider's dashboard.

What happens if I use TradeDesk AI on a shared or public computer?

We recommend logging out of the extension or removing your API key before leaving a shared computer. Since the key is stored locally, anyone with access to that browser could use your key to generate replies. For shared workstations, consider using a temporary API key with usage limits.

Pricing & Licensing

What does the free plan include, and how long does it last?

The free plan gives you 5 AI-generated replies per day and 5 saved template slots — and it never expires. You only need your own API key to get started. This is ideal for contractors who send a handful of emails daily and want to test the tool before committing.

How much does the premium plan cost, and what do I get?

Pricing details are available on the Donbrico website under the TradeDesk AI page. The premium plan removes the daily reply limit, adds unlimited template storage, and unlocks priority access to new scenarios and features. All plans use your own API key — there's no per-message fee from Donbrico.

Can I use one API key for multiple users in my company?

Yes, but check your API provider's terms. Some providers (like OpenAI) allow shared keys with usage tracking, while others may require per-user keys. TradeDesk AI doesn't restrict how many devices use the same key — each installation is independent and configured locally.

Troubleshooting

Why isn't TradeDesk AI showing up in my email compose window?

First, make sure the extension is enabled in your browser's extension manager. Then refresh your email tab. If it still doesn't appear, check that you're on a supported platform (Gmail, Outlook web, Yahoo Mail). For other web forms, you may need to click into the text field before the TradeDesk icon activates.

The AI generated a reply, but it doesn't sound like me — how do I fix this?

Update your business profile with specific details about your company's tone and style. In the extension settings, you can add custom instructions like "Always use a friendly tone" or "Include our warranty information." You can also edit the generated text directly before sending — TradeDesk AI is a drafting tool, not a final output.

I keep getting an error about my API key — what should I check?

Common issues include: expired API key, insufficient credits on your provider account, or copying extra spaces when pasting the key. Go to your API provider's dashboard, generate a new test key, and paste it carefully into TradeDesk AI's settings. If the error persists, check that you selected the correct provider (OpenAI, Groq, etc.) in the extension dropdown.

TradeDesk AI is slow or unresponsive — what can I do?

Performance depends on your API provider's response time and your internet connection. Try switching to a faster provider like Groq if you're using a slower one. Also, clear your browser cache and disable other extensions temporarily to rule out conflicts. If the issue continues, the TradeDesk AI support page on Donbrico has known workarounds for specific browser versions.
