TradeDesk AI — Foire aux Questions

Premiers Pas

Comment installer TradeDesk AI sur mon navigateur ?

Installez TradeDesk AI directement depuis le Chrome Web Store ou la boutique d'extensions de votre navigateur. Une fois ajoutée, l'icône TradeDesk apparaîtra dans votre barre d'outils — cliquez dessus pour ouvrir le panneau de configuration où vous saisirez votre clé API et paramétrerez votre profil professionnel.

De quoi ai-je besoin pour commencer à utiliser TradeDesk AI ?

Trois éléments sont nécessaires : un navigateur compatible (Chrome, Edge ou Firefox), une clé API auprès d'un fournisseur comme OpenAI, Groq ou Anthropic, et vos coordonnées professionnelles de base. Une fois la clé API saisie dans les paramètres de l'extension, vous pouvez générer des réponses immédiatement — sans inscription ni carte bancaire pour le plan gratuit.

Dois-je créer un compte sur Donbrico pour utiliser l'extension ?

Aucun compte requis. TradeDesk AI fonctionne entièrement via votre extension navigateur avec votre propre clé API. Pas de connexion cloud, pas de mot de passe à retenir, pas de base de données utilisateur — il suffit d'installer, configurer et commencer à rédiger.

Comment configurer mon profil professionnel pour la première fois ?

Ouvrez le panneau de l'extension et accédez à la section « Profil professionnel ». Renseignez le nom de votre entreprise, votre numéro de téléphone, votre email, votre numéro de licence et votre zone d'intervention. Une fois enregistrés, TradeDesk AI remplira automatiquement ces informations dans chaque réponse, devis et estimation que vous générerez — fini de saisir les mêmes données à répétition.

Fonctionnalités & Utilisation

Comment utiliser TradeDesk AI dans Gmail ou Outlook ?

Rédigez un nouvel email ou répondez à un fil existant, puis cliquez sur l'icône TradeDesk AI qui apparaît dans la fenêtre de rédaction. Sélectionnez un scénario (comme « Demande de devis » ou « Relance »), ajoutez vos notes succinctes, puis cliquez sur Générer — l'extension insérera une réponse soignée directement dans le corps du message.

Quels sont les 23+ scénarios intégrés et comment choisir le bon ?

Les scénarios couvrent les communications courantes des artisans : estimations de devis, relances de permis, confirmations de rendez-vous, avenants, rappels de garantie, etc. Lorsque vous ouvrez le menu des scénarios, chaque option inclut une brève description. En cas de doute, commencez par « Réponse rapide » — il s'adapte à toutes les notes que vous fournissez.

TradeDesk AI peut-il générer des devis et estimations, ou seulement des réponses email ?

Il gère les deux. Sélectionnez un scénario comme « Estimation formelle » ou « Devis matériaux », saisissez les détails du chantier et les prix, et TradeDesk AI mettra tout en forme dans un document professionnel. Le résultat fonctionne dans n'importe quel formulaire web, vous pouvez donc le coller dans votre CRM, outil de facturation ou portail client.

Comment fonctionne la spécialisation métier pour le chauffage, la plomberie ou l'électricité ?

Dans les paramètres de l'extension, sélectionnez votre métier principal parmi les 8 options disponibles — chauffage/climatisation, plomberie, électricité, couverture, paysagisme, multiser vice, peinture ou gros œuvre. TradeDesk AI utilise alors la terminologie spécifique à ce métier lors de la génération des réponses : un plombier obtiendra « chauffe-eau » et « canalisation », tandis qu'un électricien verra « tableau électrique » et « conduit ».

Puis-je enregistrer mes propres modèles et les réutiliser plus tard ?

Oui, le plan gratuit comprend 5 emplacements de modèles sauvegardés. Après avoir généré une réponse qui vous plaît, cliquez sur « Enregistrer comme modèle » et donnez-lui un nom. Vous pourrez charger ce modèle lors de sessions ultérieures et le régénérer avec des informations mises à jour — pratique pour les chantiers récurrents ou les promotions saisonnières.

Confidentialité & Sécurité

Où mes données sont-elles traitées lorsque j'utilise TradeDesk AI ?

Tout le traitement des données s'effectue via l'API du fournisseur que vous avez choisi — TradeDesk AI ne dispose d'aucun serveur backend. L'extension envoie vos notes directement depuis votre navigateur vers le point d'accès API que vous avez configuré (OpenAI, Groq, Anthropic, etc.), et la réponse générée revient dans votre navigateur. Rien n'est stocké ni journalisé sur l'infrastructure de Donbrico.

TradeDesk AI stocke-t-il mes emails ou informations clients ?

Non. TradeDesk AI lit le fil de discussion que vous consultez uniquement pour fournir un contexte à la génération IA. Il ne sauvegarde, ne met en cache ni ne transmet vos emails, noms de clients, adresses ou toute autre donnée personnelle vers un serveur extérieur en dehors de l'appel API que vous autorisez.

Est-il sûr d'utiliser ma propre clé API avec cette extension ?

Oui, et c'est l'approche la plus sécurisée. Votre clé API est stockée localement dans le stockage de l'extension de votre navigateur, et non sur un serveur distant. Lorsque vous générez une réponse, la clé est transmise directement au fournisseur API — comme le ferait toute application utilisant des clés API. Vous pouvez révoquer ou remplacer la clé à tout moment depuis le tableau de bord de votre fournisseur.

Que se passe-t-il si j'utilise TradeDesk AI sur un ordinateur partagé ou public ?

Nous recommandons de vous déconnecter de l'extension ou de supprimer votre clé API avant de quitter un ordinateur partagé. Comme la clé est stockée localement, toute personne ayant accès à ce navigateur pourrait utiliser votre clé pour générer des réponses. Pour les postes de travail partagés, envisagez d'utiliser une clé API temporaire avec des limites d'utilisation.

Tarifs & Licence

Que comprend le plan gratuit et combien de temps dure-t-il ?

Le plan gratuit vous offre 5 réponses générées par IA par jour et 5 emplacements de modèles sauvegardés — et il n'expire jamais. Vous avez seulement besoin de votre propre clé API pour commencer. C'est idéal pour les artisans qui envoient quelques emails par jour et souhaitent tester l'outil avant de s'engager.

Combien coûte le plan premium et qu'est-ce qu'il inclut ?

Les détails des tarifs sont disponibles sur le site Donbrico, page TradeDesk AI. Le plan premium supprime la limite quotidienne de réponses, ajoute un stockage illimité de modèles et débloque un accès prioritaire aux nouveaux scénarios et fonctionnalités. Tous les plans utilisent votre propre clé API — aucun frais par message de la part de Donbrico.

Puis-je utiliser une seule clé API pour plusieurs utilisateurs dans mon entreprise ?

Oui, mais vérifiez les conditions de votre fournisseur API. Certains fournisseurs (comme OpenAI) autorisent les clés partagées avec suivi d'utilisation, tandis que d'autres peuvent exiger des clés par utilisateur. TradeDesk AI ne limite pas le nombre d'appareils utilisant la même clé — chaque installation est indépendante et configurée localement.

Dépannage

Pourquoi TradeDesk AI ne s'affiche-t-il pas dans ma fenêtre de rédaction d'email ?

Vérifiez d'abord que l'extension est activée dans le gestionnaire d'extensions de votre navigateur. Puis actualisez votre onglet email. Si elle n'apparaît toujours pas, assurez-vous d'être sur une plateforme prise en charge (Gmail, Outlook web, Yahoo Mail). Pour d'autres formulaires web, vous devrez peut-être cliquer dans le champ de texte avant que l'icône TradeDesk ne s'active.

L'IA a généré une réponse, mais elle ne me ressemble pas — comment corriger ?

Mettez à jour votre profil professionnel avec des informations précises sur le ton et le style de votre entreprise. Dans les paramètres de l'extension, vous pouvez ajouter des instructions personnalisées comme « Toujours utiliser un ton amical » ou « Inclure nos informations de garantie ». Vous pouvez également modifier le texte généré directement avant d'envoyer — TradeDesk AI est un outil de rédaction, pas une sortie définitive.

Je reçois constamment une erreur concernant ma clé API — que vérifier ?

Les problèmes courants incluent : clé API expirée, crédits insuffisants sur votre compte fournisseur, ou espaces supplémentaires copiés en collant la clé. Rendez-vous dans le tableau de bord de votre fournisseur API, générez une nouvelle clé de test et collez-la soigneusement dans les paramètres de TradeDesk AI. Si l'erreur persiste, vérifiez que vous avez sélectionné le bon fournisseur (OpenAI, Groq, etc.) dans le menu déroulant de l'extension.

TradeDesk AI est lent ou ne répond pas — que puis-je faire ?

Les performances dépendent du temps de réponse de votre fournisseur API et de votre connexion internet. Essayez de passer à un fournisseur plus rapide comme Groq si vous utilisez un fournisseur plus lent. Videz également le cache de votre navigateur et désactivez temporairement les autres extensions pour exclure tout conflit. Si le problème persiste, la page d'assistance TradeDesk AI sur Donbrico propose des solutions connues pour certaines versions de navigateur.
