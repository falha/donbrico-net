TradeDesk AI — 자주 묻는 질문

시작하기

TradeDesk AI를 브라우저에 어떻게 설치하나요?

Chrome 웹 스토어나 사용 중인 브라우저의 확장 프로그램 마켓플레이스에서 TradeDesk AI를 직접 설치하세요. 추가하면 브라우저 툴바에 TradeDesk 아이콘이 나타납니다. 이 아이콘을 클릭하여 설정 패널을 열고 API 키를 입력하고 비즈니스 프로필을 구성하세요.

TradeDesk AI를 사용하려면 무엇이 필요한가요?

세 가지가 필요합니다: 지원되는 브라우저(Chrome, Edge 또는 Firefox), OpenAI, Groq, Anthropic 같은 제공업체의 API 키, 그리고 기본 비즈니스 정보입니다. 확장 프로그램 설정에 API 키를 입력하면 즉시 답변 생성을 시작할 수 있습니다. 무료 플랜에는 계정 등록이나 신용카드가 필요하지 않습니다.

확장 프로그램을 사용하려면 Donbrico에 계정을 만들어야 하나요?

계정이 필요하지 않습니다. TradeDesk AI는 사용자 본인의 API 키를 사용하여 브라우저 확장 프로그램 내에서 완전히 작동합니다. 클라우드 로그인, 기억해야 할 비밀번호, 사용자 데이터베이스가 없습니다. 그냥 설치하고 설정한 후 작성을 시작하면 됩니다.

처음으로 비즈니스 프로필을 설정하려면 어떻게 하나요?

확장 프로그램 패널을 열고 "비즈니스 프로필" 섹션으로 이동하세요. 회사명, 전화번호, 이메일, 면허 번호, 서비스 지역을 입력합니다. 저장하면 TradeDesk AI가 모든 답변, 견적, 예상 견적서에 이 정보를 자동으로 입력해 주므로 같은 정보를 반복해서 입력할 필요가 없습니다.

기능 및 사용법

Gmail이나 Outlook에서 TradeDesk AI를 어떻게 사용하나요?

새 이메일을 작성하거나 기존 스레드에 답장을 한 다음, 이메일 창 안에 나타나는 TradeDesk AI 아이콘을 클릭하세요. 시나리오(예: "견적 요청" 또는 "후속 조치")를 선택하고 간단한 메모를 추가한 후 "생성"을 클릭하면 확장 프로그램이 정리된 답변을 메시지 본문에 직접 삽입합니다.

23개 이상의 내장 시나리오는 무엇이며, 어떻게 올바른 시나리오를 선택하나요?

시나리오는 일반적인 계약자 커뮤니케이션을 다룹니다: 견적 예상, 허가 후속 조치, 작업 확인, 변경 주문, 보증 알림 등. 시나리오 메뉴를 열면 각 옵션에 간단한 설명이 포함되어 있습니다. 잘 모르겠다면 "빠른 답장"으로 시작하세요. 제공한 메모에 맞게 자동으로 조정됩니다.

TradeDesk AI는 이메일 답변만 생성하나요, 아니면 견적과 예상 견적서도 생성하나요?

둘 다 처리합니다. "공식 견적서"나 "자재 견적" 같은 시나리오를 선택하고 작업 세부 정보와 가격을 입력하면 TradeDesk AI가 모든 것을 전문적인 문서로 포맷팅합니다. 출력물은 모든 웹 양식에서 작동하므로 CRM, 인보이스 도구, 고객 포털에 붙여넣을 수 있습니다.

HVAC, 배관, 전기 작업에 대한 업종 특화 기능은 어떻게 작동하나요?

확장 프로그램 설정에서 8개 옵션(HVAC, 배관, 전기, 지붕, 조경, 핸디맨, 도장, 일반 계약) 중 기본 업종을 선택하세요. 그러면 TradeDesk AI가 답변 생성 시 해당 업종의 전문 용어를 사용합니다. 예를 들어 배관공에게는 "온수기"와 "배수관"을, 전기 기술자에게는 "차단기 패널"과 "전선관"을 사용합니다.

템플릿을 저장하고 나중에 재사용할 수 있나요?

네, 무료 플랜에는 5개의 저장된 템플릿 슬롯이 포함되어 있습니다. 마음에 드는 답변을 생성한 후 "템플릿으로 저장"을 클릭하고 이름을 지정하세요. 이후 세션에서 해당 템플릿을 불러와 업데이트된 세부 정보로 다시 생성할 수 있습니다. 반복 작업이나 계절별 프로모션에 유용합니다.

개인정보 및 보안

TradeDesk AI를 사용할 때 내 데이터는 어디에서 처리되나요?

모든 데이터 처리는 사용자가 선택한 AI 제공업체의 API를 통해 이루어집니다. TradeDesk AI 자체에는 백엔드 서버가 없습니다. 확장 프로그램은 사용자의 메모를 브라우저에서 설정한 API 엔드포인트(OpenAI, Groq, Anthropic 등)로 직접 보내고, 생성된 답변은 다시 브라우저로 돌아옵니다. Donbrico의 인프라에는 아무것도 저장되거나 기록되지 않습니다.

TradeDesk AI가 내 이메일이나 고객 정보를 저장하나요?

아니요. TradeDesk AI는 현재 보고 있는 이메일 스레드만 읽어 AI 생성에 컨텍스트를 제공합니다. 사용자가 승인한 API 호출 외에는 이메일, 고객 이름, 주소 또는 기타 개인 데이터를 어떤 서버에도 저장, 캐싱 또는 전송하지 않습니다.

이 확장 프로그램에서 내 API 키를 사용하는 것이 안전한가요?

네, 가장 안전한 방법입니다. API 키는 원격 서버가 아닌 브라우저의 확장 프로그램 저장소에 로컬로 저장됩니다. 답변을 생성할 때 키는 API 제공업체에 직접 전달됩니다. 이는 API 키를 사용하는 모든 앱과 동일한 방식입니다. 언제든지 제공업체 대시보드에서 키를 취소하거나 교체할 수 있습니다.

공용 컴퓨터나 공유 컴퓨터에서 TradeDesk AI를 사용하면 어떻게 되나요?

공유 컴퓨터를 떠나기 전에 확장 프로그램에서 로그아웃하거나 API 키를 제거하는 것이 좋습니다. 키가 로컬에 저장되어 있으므로 해당 브라우저에 접근할 수 있는 사람이 키를 사용하여 답변을 생성할 수 있습니다. 공유 워크스테이션의 경우 사용량 제한이 있는 임시 API 키를 사용하는 것을 고려하세요.

가격 및 라이선스

무료 플랜에는 무엇이 포함되어 있으며, 얼마나 지속되나요?

무료 플랜은 하루 5개의 AI 생성 답변과 5개의 저장된 템플릿 슬롯을 제공하며 만료되지 않습니다. 시작하려면 자신의 API 키만 있으면 됩니다. 하루에 몇 통의 이메일을 보내는 계약자나 도구를 먼저 테스트해보려는 분들에게 이상적입니다.

프리미엄 플랜의 가격은 얼마이며, 무엇을 제공하나요?

가격 세부 정보는 Donbrico 웹사이트의 TradeDesk AI 페이지에서 확인할 수 있습니다. 프리미엄 플랜은 일일 답변 제한을 없애고, 무제한 템플릿 저장소를 제공하며, 새로운 시나리오와 기능에 대한 우선 접근 권한을 제공합니다. 모든 플랜은 사용자 본인의 API 키를 사용하며 Donbrico의 메시지당 수수료는 없습니다.

회사 내 여러 사용자가 하나의 API 키를 사용할 수 있나요?

네, 하지만 API 제공업체의 약관을 확인하세요. 일부 제공업체(OpenAI 등)는 사용량 추적이 가능한 공유 키를 허용하지만, 다른 제공업체는 사용자별 키를 요구할 수 있습니다. TradeDesk AI는 동일한 키를 사용하는 기기 수를 제한하지 않습니다. 각 설치는 독립적이며 로컬로 구성됩니다.

문제 해결

TradeDesk AI가 이메일 작성 창에 나타나지 않는 이유는 무엇인가요?

먼저 브라우저의 확장 프로그램 관리자에서 확장 프로그램이 활성화되어 있는지 확인하세요. 그런 다음 이메일 탭을 새로고침하세요. 그래도 나타나지 않으면 지원되는 플랫폼(Gmail, Outlook 웹, Yahoo Mail)을 사용하고 있는지 확인하세요. 다른 웹 양식의 경우 TradeDesk 아이콘이 활성화되기 전에 텍스트 필드를 클릭해야 할 수도 있습니다.

AI가 답변을 생성했지만 제 스타일과 맞지 않습니다. 어떻게 수정하나요?

비즈니스 프로필을 업데이트하여 회사의 어조와 스타일에 대한 구체적인 정보를 추가하세요. 확장 프로그램 설정에서 "항상 친근한 어조 사용"이나 "보증 정보 포함" 같은 사용자 지정 지침을 추가할 수 있습니다. 보내기 전에 생성된 텍스트를 직접 편집할 수도 있습니다. TradeDesk AI는 초안 작성 도구이지 최종 출력물이 아닙니다.

API 키 관련 오류가 계속 발생합니다. 무엇을 확인해야 하나요?

일반적인 문제는 다음과 같습니다: API 키 만료, 제공업체 계정의 크레딧 부족, 키를 붙여넣을 때 불필요한 공백이 포함된 경우. API 제공업체 대시보드로 이동하여 새 테스트 키를 생성하고 TradeDesk AI 설정에 조심스럽게 붙여넣으세요. 오류가 지속되면 확장 프로그램 드롭다운에서 올바른 제공업체(OpenAI, Groq 등)를 선택했는지 확인하세요.

TradeDesk AI가 느리거나 응답하지 않습니다. 어떻게 해야 하나요?

성능은 API 제공업체의 응답 시간과 인터넷 연결에 따라 달라집니다. 느린 제공업체를 사용 중이라면 Groq 같은 더 빠른 제공업체로 전환해 보세요. 또한 브라우저 캐시를 지우고 다른 확장 프로그램을 일시적으로 비활성화하여 충돌 가능성을 배제하세요. 문제가 지속되면 Donbrico의 TradeDesk AI 지원 페이지에서 특정 브라우저 버전에 대한 알려진 해결 방법을 확인할 수 있습니다.
