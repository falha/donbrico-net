TradeDesk AI — Domande Frequenti

Per Iniziare

Come installo TradeDesk AI sul mio browser?

Installa TradeDesk AI direttamente dal Chrome Web Store o dal marketplace delle estensioni del tuo browser. Dopo l'aggiunta, vedrai l'icona di TradeDesk nella barra degli strumenti del browser — cliccaci per aprire il pannello di configurazione dove inserire la tua chiave API e impostare il profilo della tua attività.

Cosa mi serve per iniziare a usare TradeDesk AI?

Ti servono tre cose: un browser supportato (Chrome, Edge o Firefox), una chiave API da un fornitore come OpenAI, Groq o Anthropic, e i dati base della tua attività. Una volta inserita la chiave API nelle impostazioni dell'estensione, puoi iniziare subito a generare risposte — nessuna registrazione o carta di credito richiesta per il piano gratuito.

Devo creare un account su Donbrico per usare l'estensione?

Nessun account è necessario. TradeDesk AI funziona interamente tramite l'estensione del tuo browser usando la tua chiave API personale. Non c'è login sul cloud, nessuna password da ricordare e nessun database utenti — basta installare, configurare e iniziare a scrivere bozze.

Come configuro il profilo della mia attività per la prima volta?

Apri il pannello dell'estensione e vai alla sezione "Profilo Attività". Inserisci il nome della tua azienda, numero di telefono, email, numero di licenza e zona di servizio. Una volta salvato, TradeDesk AI inserirà automaticamente questi dati in ogni risposta, preventivo e stima che generi — risparmiandoti di dover digitare le stesse informazioni ripetutamente.

Funzionalità e Utilizzo

Come uso TradeDesk AI in Gmail o Outlook?

Componi una nuova email o rispondi a una conversazione esistente, poi clicca sull'icona di TradeDesk AI che appare nella finestra dell'email. Seleziona uno scenario (come "Richiesta Preventivo" o "Follow-Up"), aggiungi le tue note approssimative e clicca Genera — l'estensione inserirà una risposta curata direttamente nel corpo del messaggio.

Quali sono gli oltre 23 scenari integrati e come scelgo quello giusto?

Gli scenari coprono le comunicazioni tipiche dei professionisti: stime di preventivo, follow-up sui permessi, conferme di lavoro, ordini di variazione, promemoria di garanzia e altro. Quando apri il menu degli scenari, ogni opzione include una breve descrizione. Se non sei sicuro, inizia con "Risposta Rapida" — si adatta a qualsiasi nota tu fornisca.

TradeDesk AI può generare preventivi e stime, o solo risposte email?

Gestisce entrambi. Seleziona uno scenario come "Stima Formale" o "Preventivo Materiali", inserisci i dettagli del lavoro e i prezzi, e TradeDesk AI formatterà tutto in un documento professionale. L'output funziona in qualsiasi modulo web, quindi puoi incollarlo nel tuo CRM, nel software di fatturazione o nel portale clienti.

Come funziona la specializzazione per settore per HVAC, idraulica o elettricità?

Nelle impostazioni dell'estensione, seleziona il tuo settore principale dall'elenco di 8 opzioni — HVAC, idraulica, elettricità, coperture, giardinaggio, tuttofare, pittura o edilizia generale. TradeDesk AI utilizza quindi la terminologia specifica del settore quando genera risposte, così un idraulico ottiene "scaldabagno" e "tubo di scarico" mentre un elettricista ottiene "quadro elettrico" e "canalina".

Posso salvare i miei modelli personalizzati e riutilizzarli in seguito?

Sì, il piano gratuito include 5 slot per modelli salvati. Dopo aver generato una risposta che ti piace, clicca "Salva come Modello" e dagli un nome. Puoi caricare quel modello in sessioni future e rigenerarlo con dettagli aggiornati — utile per lavori ricorrenti o promozioni stagionali.

Privacy e Sicurezza

Dove vengono elaborati i miei dati quando uso TradeDesk AI?

Tutta l'elaborazione dei dati avviene tramite l'API del fornitore AI che hai scelto — TradeDesk AI stesso non ha server backend. L'estensione invia le tue note direttamente dal tuo browser all'endpoint API che configuri (OpenAI, Groq, Anthropic, ecc.), e la risposta generata torna al tuo browser. Niente viene memorizzato o registrato sull'infrastruttura di Donbrico.

TradeDesk AI memorizza le mie email o le informazioni dei clienti?

No. TradeDesk AI legge la conversazione email che stai visualizzando solo per fornire contesto alla generazione dell'AI. Non salva, memorizza nella cache o trasmette le tue email, i nomi dei clienti, gli indirizzi o altri dati personali a server esterni oltre alla chiamata API che autorizzi.

È sicuro usare la mia chiave API personale con questa estensione?

Sì, ed è l'approccio più sicuro. La tua chiave API è memorizzata localmente nell'archivio dell'estensione del tuo browser, non su un server remoto. Quando generi una risposta, la chiave viene passata direttamente al fornitore API — allo stesso modo in cui funziona qualsiasi app che usa chiavi API. Puoi revocare o ruotare la chiave in qualsiasi momento dal pannello di controllo del tuo fornitore.

Cosa succede se uso TradeDesk AI su un computer condiviso o pubblico?

Ti consigliamo di disconnetterti dall'estensione o rimuovere la tua chiave API prima di lasciare un computer condiviso. Poiché la chiave è memorizzata localmente, chiunque abbia accesso a quel browser potrebbe usare la tua chiave per generare risposte. Per postazioni di lavoro condivise, considera l'uso di una chiave API temporanea con limiti di utilizzo.

Prezzi e Licenze

Cosa include il piano gratuito e quanto dura?

Il piano gratuito ti dà 5 risposte generate dall'AI al giorno e 5 slot per modelli salvati — e non scade mai. Hai solo bisogno della tua chiave API per iniziare. È ideale per professionisti che inviano una manciata di email al giorno e vogliono testare lo strumento prima di impegnarsi.

Quanto costa il piano premium e cosa ottengo?

I dettagli sui prezzi sono disponibili sul sito Donbrico nella pagina TradeDesk AI. Il piano premium rimuove il limite giornaliero di risposte, aggiunge spazio illimitato per i modelli e sblocca l'accesso prioritario a nuovi scenari e funzionalità. Tutti i piani usano la tua chiave API personale — nessuna commissione per messaggio da Donbrico.

Posso usare una chiave API per più utenti nella mia azienda?

Sì, ma verifica i termini del tuo fornitore API. Alcuni fornitori (come OpenAI) consentono chiavi condivise con monitoraggio dell'utilizzo, mentre altri potrebbero richiedere chiavi per singolo utente. TradeDesk AI non limita quanti dispositivi possono usare la stessa chiave — ogni installazione è indipendente e configurata localmente.

Risoluzione dei Problemi

Perché TradeDesk AI non appare nella finestra di composizione della mia email?

Prima di tutto, assicurati che l'estensione sia abilitata nel gestore delle estensioni del tuo browser. Poi aggiorna la scheda della tua email. Se ancora non appare, verifica di essere su una piattaforma supportata (Gmail, Outlook web, Yahoo Mail). Per altri moduli web, potrebbe essere necessario cliccare nel campo di testo prima che l'icona di TradeDesk si attivi.

L'AI ha generato una risposta, ma non suona come me — come posso risolvere?

Aggiorna il tuo profilo attività con dettagli specifici sul tono e lo stile della tua azienda. Nelle impostazioni dell'estensione, puoi aggiungere istruzioni personalizzate come "Usa sempre un tono amichevole" o "Includi le informazioni sulla nostra garanzia." Puoi anche modificare il testo generato direttamente prima di inviarlo — TradeDesk AI è uno strumento di bozza, non un output finale.

Continuo a ricevere un errore sulla mia chiave API — cosa dovrei controllare?

I problemi comuni includono: chiave API scaduta, crediti insufficienti sul tuo account fornitore, o spazi extra copiati incollando la chiave. Vai al pannello di controllo del tuo fornitore API, genera una nuova chiave di test e incollala attentamente nelle impostazioni di TradeDesk AI. Se l'errore persiste, verifica di aver selezionato il fornitore corretto (OpenAI, Groq, ecc.) nel menu a discesa dell'estensione.

TradeDesk AI è lento o non risponde — cosa posso fare?

Le prestazioni dipendono dal tempo di risposta del tuo fornitore API e dalla tua connessione internet. Prova a passare a un fornitore più veloce come Groq se ne stai usando uno più lento. Inoltre, svuota la cache del browser e disabilita temporaneamente altre estensioni per escludere conflitti. Se il problema persiste, la pagina di supporto di TradeDesk AI su Donbrico ha soluzioni note per versioni specifiche del browser.
