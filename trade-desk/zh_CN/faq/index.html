TradeDesk AI — 常见问题解答

入门指南

如何在浏览器中安装 TradeDesk AI？

直接从 Chrome 网上应用店或浏览器的扩展市场安装 TradeDesk AI。安装后，浏览器工具栏中会出现 TradeDesk 图标——点击打开设置面板，输入您的 API 密钥并配置您的业务资料。

开始使用 TradeDesk AI 需要什么？

您需要三样东西：受支持的浏览器（Chrome、Edge 或 Firefox）、来自 OpenAI、Groq 或 Anthropic 等提供商的 API 密钥，以及您的基本业务信息。在扩展设置中输入 API 密钥后，即可立即开始生成回复——免费计划无需注册账户或提供信用卡。

我需要注册 Donbrico 账户才能使用扩展吗？

不需要。TradeDesk AI 完全通过您的浏览器扩展运行，使用您自己的 API 密钥。无需云登录、无需记住密码、也没有用户数据库——只需安装、配置，即可开始起草。

如何首次设置我的业务资料？

打开扩展面板，导航至"业务资料"部分。填写公司名称、电话号码、电子邮件、执照编号和服务区域。保存后，TradeDesk AI 会自动将这些详细信息填入您生成的每一条回复、报价和估算中——省去您重复输入相同信息的麻烦。

功能与使用

如何在 Gmail 或 Outlook 中使用 TradeDesk AI？

撰写新邮件或回复现有邮件线程，然后点击邮件窗口中出现的 TradeDesk AI 图标。选择一个场景（如"报价请求"或"跟进"），添加您的粗略备注，点击生成——扩展会将润色后的回复直接插入您的邮件正文。

什么是 23 种以上内置场景？如何选择正确的场景？

场景涵盖常见的承包商沟通内容：报价估算、许可证跟进、工作确认、变更订单、保修提醒等。打开场景菜单时，每个选项都包含简短描述。如果不确定，从"快速回复"开始——它会根据您提供的任何备注进行调整。

TradeDesk AI 能生成报价和估算吗，还是只能生成邮件回复？

两者都能处理。选择"正式估算"或"材料报价"等场景，输入工作详情和定价，TradeDesk AI 会将所有内容格式化为专业文档。输出适用于任何网页表单，因此您可以将其粘贴到 CRM、开票工具或客户门户中。

针对暖通空调、管道或电气工作的行业专业化功能如何运作？

在扩展设置中，从 8 个选项中选择您的主要行业——暖通空调、管道、电气、屋顶、园林绿化、杂工、油漆或综合承包。TradeDesk AI 在生成回复时会使用该行业的专业术语，因此管道工会看到"热水器"和"排水管"，而电气工会看到"断路器面板"和"线管"。

我可以保存自己的模板并重复使用吗？

可以，免费计划包含 5 个模板保存槽。生成您喜欢的回复后，点击"保存为模板"并命名。您可以在后续会话中加载该模板，并用更新的详细信息重新生成——非常适合重复性工作或季节性促销。

隐私与安全

使用 TradeDesk AI 时，我的数据在哪里处理？

所有数据处理都通过您选择的 AI 提供商的 API 进行——TradeDesk AI 本身没有后端服务器。扩展将您的备注直接从浏览器发送到您配置的 API 端点（OpenAI、Groq、Anthropic 等），生成的回复返回您的浏览器。Donbrico 的基础设施上不存储或记录任何内容。

TradeDesk AI 会存储我的电子邮件或客户信息吗？

不会。TradeDesk AI 仅读取您当前查看的邮件线程，以便为 AI 生成提供上下文。它不会保存、缓存或传输您的电子邮件、客户姓名、地址或任何其他个人数据到您授权的 API 调用之外的任何服务器。

使用我自己的 API 密钥与此扩展安全吗？

是的，这是最安全的方式。您的 API 密钥本地存储在浏览器的扩展存储中，而非任何远程服务器。当您生成回复时，密钥直接传递给 API 提供商——这与任何使用 API 密钥的应用工作方式相同。您可以随时从提供商的仪表板撤销或轮换密钥。

如果在共享或公共计算机上使用 TradeDesk AI 会怎样？

我们建议在离开共享计算机前退出扩展或移除您的 API 密钥。由于密钥本地存储，任何能访问该浏览器的人都可以使用您的密钥生成回复。对于共享工作站，建议使用带有使用限制的临时 API 密钥。

定价与许可

免费计划包含什么？有效期多久？

免费计划每天提供 5 次 AI 生成的回复和 5 个模板保存槽——并且永不过期。您只需要自己的 API 密钥即可开始使用。这非常适合每天发送少量邮件并希望在投入前测试工具的承包商。

高级计划费用是多少？我能得到什么？

定价详情可在 Donbrico 网站的 TradeDesk AI 页面上查看。高级计划取消了每日回复限制，提供无限模板存储，并解锁对新场景和功能的优先访问权限。所有计划都使用您自己的 API 密钥——Donbrico 不收取按条消息费用。

我可以为公司的多个用户使用同一个 API 密钥吗？

可以，但请查看您的 API 提供商条款。某些提供商（如 OpenAI）允许共享密钥并跟踪使用情况，而其他提供商可能要求每个用户使用独立密钥。TradeDesk AI 不限制使用同一密钥的设备数量——每个安装都是独立的，并在本地配置。

故障排除

为什么 TradeDesk AI 没有出现在我的邮件撰写窗口中？

首先，确保扩展在浏览器的扩展管理器中已启用。然后刷新您的邮件标签页。如果仍然不显示，检查您是否在受支持的平台上（Gmail、Outlook 网页版、Yahoo Mail）。对于其他网页表单，您可能需要先点击文本字段，TradeDesk 图标才会激活。

AI 生成了回复，但听起来不像我的风格——如何解决？

使用关于公司语气和风格的具体详细信息更新您的业务资料。在扩展设置中，您可以添加自定义指令，例如"始终使用友好语气"或"包含我们的保修信息"。您也可以在发送前直接编辑生成的文本——TradeDesk AI 是起草工具，而非最终输出。

我不断收到有关 API 密钥的错误——应该检查什么？

常见问题包括：API 密钥过期、提供商账户积分不足、或粘贴密钥时复制了多余空格。前往您的 API 提供商仪表板，生成新的测试密钥，并小心地粘贴到 TradeDesk AI 的设置中。如果错误仍然存在，检查您在扩展下拉菜单中是否选择了正确的提供商（OpenAI、Groq 等）。

TradeDesk AI 运行缓慢或无响应——我能做什么？

性能取决于您的 API 提供商响应时间和互联网连接。如果您使用较慢的提供商，尝试切换到更快的提供商（如 Groq）。同时，清除浏览器缓存并暂时禁用其他扩展以排除冲突。如果问题持续，Donbrico 上的 TradeDesk AI 支持页面提供了针对特定浏览器版本的已知解决方法。
