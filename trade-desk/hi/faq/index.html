TradeDesk AI — अक्सर पूछे जाने वाले प्रश्न

शुरुआत कैसे करें

मैं अपने ब्राउज़र पर TradeDesk AI कैसे इंस्टॉल करूं?

TradeDesk AI को सीधे Chrome Web Store या अपने ब्राउज़र के एक्सटेंशन मार्केटप्लेस से इंस्टॉल करें। इसे जोड़ने के बाद, आपके ब्राउज़र टूलबार में TradeDesk आइकन दिखाई देगा — इसे क्लिक करके सेटअप पैनल खोलें, जहां आप अपनी API key दर्ज करेंगे और अपना बिज़नेस प्रोफ़ाइल कॉन्फ़िगर करेंगे।

TradeDesk AI का उपयोग शुरू करने के लिए मुझे क्या चाहिए?

आपको तीन चीज़ें चाहिए: एक सपोर्टेड ब्राउज़र (Chrome, Edge, या Firefox), OpenAI, Groq, या Anthropic जैसे प्रदाता से एक API key, और आपके बिज़नेस की बुनियादी जानकारी। एक्सटेंशन सेटिंग्स में API key डालने के बाद, आप तुरंत रिप्लाई जनरेट करना शुरू कर सकते हैं — फ्री प्लान के लिए कोई अकाउंट रजिस्ट्रेशन या क्रेडिट कार्ड की आवश्यकता नहीं है।

क्या एक्सटेंशन का उपयोग करने के लिए मुझे Donbrico पर अकाउंट बनाना होगा?

किसी अकाउंट की आवश्यकता नहीं है। TradeDesk AI आपकी अपनी API key का उपयोग करके पूरी तरह से आपके ब्राउज़र एक्सटेंशन के माध्यम से चलता है। कोई क्लाउड लॉगिन नहीं, याद रखने के लिए कोई पासवर्ड नहीं, और कोई यूज़र डेटाबेस नहीं — बस इंस्टॉल करें, कॉन्फ़िगर करें, और ड्राफ्ट करना शुरू करें।

मैं पहली बार अपना बिज़नेस प्रोफ़ाइल कैसे सेट करूं?

एक्सटेंशन पैनल खोलें और "Business Profile" सेक्शन पर जाएं। अपनी कंपनी का नाम, फ़ोन नंबर, ईमेल, लाइसेंस नंबर और सेवा क्षेत्र भरें। सेव करने के बाद, TradeDesk AI आपके द्वारा जनरेट किए जाने वाले हर रिप्लाई, कोट और एस्टीमेट में ये विवरण ऑटो-फिल करेगा — जिससे आपको एक ही जानकारी बार-बार टाइप करने से बचाएगा।

फीचर्स और उपयोग

मैं Gmail या Outlook के अंदर TradeDesk AI का उपयोग कैसे करूं?

एक नया ईमेल लिखें या किसी मौजूदा थ्रेड का जवाब दें, फिर ईमेल विंडो के अंदर दिखाई देने वाले TradeDesk AI आइकन पर क्लिक करें। कोई सीनारियो चुनें (जैसे "Quote Request" या "Follow-Up"), अपने मोटे नोट्स जोड़ें, और Generate पर क्लिक करें — एक्सटेंशन सीधे आपके मैसेज बॉडी में एक पॉलिश्ड रिप्लाई डाल देगा।

23+ बिल्ट-इन सीनारियो क्या हैं, और मैं सही कैसे चुनूं?

सीनारियो सामान्य कॉन्ट्रैक्टर संचार को कवर करते हैं: कोट एस्टीमेट, परमिट फॉलो-अप, जॉब कन्फर्मेशन, चेंज ऑर्डर, वारंटी रिमाइंडर, और भी बहुत कुछ। जब आप सीनारियो मेनू खोलते हैं, तो प्रत्येक विकल्प में एक छोटा विवरण शामिल होता है। अगर आप अनिश्चित हैं, तो "Quick Reply" से शुरू करें — यह आपके द्वारा दिए गए किसी भी नोट्स के अनुसार ढल जाता है।

क्या TradeDesk AI कोट और एस्टीमेट जनरेट कर सकता है, या सिर्फ ईमेल रिप्लाई?

यह दोनों करता है। "Formal Estimate" या "Material Quote" जैसा कोई सीनारियो चुनें, जॉब विवरण और मूल्य निर्धारण दर्ज करें, और TradeDesk AI सब कुछ एक प्रोफेशनल डॉक्यूमेंट में फॉर्मेट कर देगा। आउटपुट किसी भी वेब फॉर्म में काम करता है, ताकि आप इसे अपने CRM, इनवॉइसिंग टूल या कस्टमर पोर्टल में पेस्ट कर सकें।

HVAC, प्लंबिंग या इलेक्ट्रिकल काम के लिए ट्रेड स्पेशलाइज़ेशन कैसे काम करता है?

एक्सटेंशन सेटिंग्स में, 8 विकल्पों की सूची से अपना प्राथमिक ट्रेड चुनें — HVAC, प्लंबिंग, इलेक्ट्रिकल, रूफिंग, लैंडस्केपिंग, हैंडीमैन, पेंटिंग, या जनरल कॉन्ट्रैक्टिंग। फिर TradeDesk AI रिप्लाई जनरेट करते समय उस ट्रेड के लिए उद्योग-विशिष्ट शब्दावली का उपयोग करता है, जिससे एक प्लंबर को "water heater" और "drain line" मिलता है जबकि एक इलेक्ट्रीशियन को "breaker panel" और "conduit" मिलता है।

क्या मैं अपने टेम्पलेट सेव कर सकता हूं और बाद में उनका पुन: उपयोग कर सकता हूं?

हां, फ्री प्लान में 5 सेव किए गए टेम्पलेट स्लॉट शामिल हैं। आपको पसंद आने वाली रिप्लाई जनरेट करने के बाद, "Save as Template" पर क्लिक करें और इसे एक नाम दें। आप भविष्य के सत्रों में उस टेम्पलेट को लोड कर सकते हैं और अपडेटेड विवरण के साथ इसे पुन: जनरेट कर सकते हैं — बार-बार होने वाले कामों या मौसमी प्रमोशन के लिए उपयोगी।

गोपनीयता और सुरक्षा

जब मैं TradeDesk AI का उपयोग करता हूं तो मेरा डेटा कहां प्रोसेस होता है?

सभी डेटा प्रोसेसिंग आपके चुने हुए AI प्रदाता के API के माध्यम से होती है — TradeDesk AI के पास स्वयं कोई बैकएंड सर्वर नहीं है। एक्सटेंशन आपके नोट्स सीधे आपके ब्राउज़र से उस API एंडपॉइंट पर भेजता है जिसे आप कॉन्फ़िगर करते हैं (OpenAI, Groq, Anthropic, आदि), और जनरेट की गई रिप्लाई आपके ब्राउज़र में वापस आती है। Donbrico के इंफ्रास्ट्रक्चर पर कुछ भी स्टोर या लॉग नहीं किया जाता है।

क्या TradeDesk AI मेरे ईमेल या ग्राहक जानकारी स्टोर करता है?

नहीं। TradeDesk AI AI जनरेशन के लिए संदर्भ प्रदान करने के लिए केवल उस ईमेल थ्रेड को पढ़ता है जिसे आप वर्तमान में देख रहे हैं। यह आपके ईमेल, ग्राहकों के नाम, पते, या किसी अन्य व्यक्तिगत डेटा को आपके द्वारा अधिकृत API कॉल के अलावा किसी भी सर्वर पर सेव, कैश या ट्रांसमिट नहीं करता है।

क्या इस एक्सटेंशन के साथ अपनी API key का उपयोग करना सुरक्षित है?

हां, और यह सबसे सुरक्षित तरीका है। आपकी API key आपके ब्राउज़र के एक्सटेंशन स्टोरेज में स्थानीय रूप से संग्रहीत होती है, किसी रिमोट सर्वर पर नहीं। जब आप कोई रिप्लाई जनरेट करते हैं, तो key सीधे API प्रदाता को भेजी जाती है — उसी तरह जैसे API key का उपयोग करने वाला कोई भी ऐप काम करता है। आप अपने प्रदाता के डैशबोर्ड से किसी भी समय key को रिवोक या रोटेट कर सकते हैं।

अगर मैं शेयर्ड या पब्लिक कंप्यूटर पर TradeDesk AI का उपयोग करूं तो क्या होगा?

हम शेयर्ड कंप्यूटर छोड़ने से पहले एक्सटेंशन से लॉग आउट करने या अपनी API key हटाने की सलाह देते हैं। चूंकि key स्थानीय रूप से संग्रहीत होती है, उस ब्राउज़र तक पहुंच रखने वाला कोई भी व्यक्ति रिप्लाई जनरेट करने के लिए आपकी key का उपयोग कर सकता है। शेयर्ड वर्कस्टेशन के लिए, उपयोग सीमा वाली अस्थायी API key का उपयोग करने पर विचार करें।

मूल्य निर्धारण और लाइसेंसिंग

फ्री प्लान में क्या शामिल है, और यह कितने समय तक चलता है?

फ्री प्लान आपको प्रति दिन 5 AI-जनरेटेड रिप्लाई और 5 सेव किए गए टेम्पलेट स्लॉट देता है — और यह कभी समाप्त नहीं होता। शुरू करने के लिए आपको केवल अपनी API key चाहिए। यह उन कॉन्ट्रैक्टरों के लिए आदर्श है जो रोजाना कुछ ईमेल भेजते हैं और प्रतिबद्ध होने से पहले टूल का परीक्षण करना चाहते हैं।

प्रीमियम प्लान की कीमत कितनी है, और मुझे क्या मिलता है?

मूल्य निर्धारण विवरण Donbrico वेबसाइट पर TradeDesk AI पेज के अंतर्गत उपलब्ध हैं। प्रीमियम प्लान दैनिक रिप्लाई सीमा हटाता है, असीमित टेम्पलेट स्टोरेज जोड़ता है, और नए सीनारियो और फीचर्स तक प्राथमिकता पहुंच अनलॉक करता है। सभी प्लान आपकी अपनी API key का उपयोग करते हैं — Donbrico की ओर से कोई प्रति-मैसेज शुल्क नहीं है।

क्या मैं अपनी कंपनी में कई उपयोगकर्ताओं के लिए एक API key का उपयोग कर सकता हूं?

हां, लेकिन अपने API प्रदाता की शर्तों की जांच करें। कुछ प्रदाता (जैसे OpenAI) उपयोग ट्रैकिंग के साथ शेयर्ड keys की अनुमति देते हैं, जबकि अन्य को प्रति-उपयोगकर्ता keys की आवश्यकता हो सकती है। TradeDesk AI यह प्रतिबंधित नहीं करता है कि एक ही key का उपयोग कितने डिवाइस कर सकते हैं — प्रत्येक इंस्टॉलेशन स्वतंत्र है और स्थानीय रूप से कॉन्फ़िगर किया गया है।

समस्या निवारण

TradeDesk AI मेरे ईमेल कंपोज़ विंडो में क्यों नहीं दिख रहा है?

पहले, सुनिश्चित करें कि आपके ब्राउज़र के एक्सटेंशन मैनेजर में एक्सटेंशन सक्षम है। फिर अपने ईमेल टैब को रिफ्रेश करें। अगर यह अभी भी दिखाई नहीं देता है, तो जांचें कि आप एक सपोर्टेड प्लेटफॉर्म (Gmail, Outlook web, Yahoo Mail) पर हैं। अन्य वेब फॉर्म के लिए, TradeDesk आइकन सक्रिय होने से पहले आपको टेक्स्ट फील्ड पर क्लिक करने की आवश्यकता हो सकती है।

AI ने एक रिप्लाई जनरेट की, लेकिन यह मेरी तरह नहीं लगती — मैं इसे कैसे ठीक करूं?

अपनी कंपनी के टोन और शैली के बारे में विशिष्ट विवरण के साथ अपने बिज़नेस प्रोफ़ाइल को अपडेट करें। एक्सटेंशन सेटिंग्स में, आप कस्टम निर्देश जोड़ सकते हैं जैसे "हमेशा मैत्रीपूर्ण लहजे का उपयोग करें" या "हमारी वारंटी जानकारी शामिल करें।" आप भेजने से पहले जनरेटेड टेक्स्ट को सीधे संपादित भी कर सकते हैं — TradeDesk AI एक ड्राफ्टिंग टूल है, अंतिम आउटपुट नहीं।

मुझे अपनी API key के बारे में लगातार एरर आ रही है — मुझे क्या जांचना चाहिए?

सामान्य समस्याओं में शामिल हैं: समाप्त हो चुकी API key, आपके प्रदाता अकाउंट में अपर्याप्त क्रेडिट, या key पेस्ट करते समय अतिरिक्त स्पेस कॉपी करना। अपने API प्रदाता के डैशबोर्ड पर जाएं, एक नई टेस्ट key जनरेट करें, और इसे ध्यान से TradeDesk AI की सेटिंग्स में पेस्ट करें। अगर एरर बनी रहती है, तो जांचें कि आपने एक्सटेंशन ड्रॉपडाउन में सही प्रदाता (OpenAI, Groq, आदि) चुना है।

TradeDesk AI धीमा या अनुत्तरदायी है — मैं क्या कर सकता हूं?

प्रदर्शन आपके API प्रदाता की प्रतिक्रिया समय और आपके इंटरनेट कनेक्शन पर निर्भर करता है। यदि आप धीमे प्रदाता का उपयोग कर रहे हैं तो Groq जैसे तेज़ प्रदाता पर स्विच करने का प्रयास करें। साथ ही, विरोधों को रोकने के लिए अपना ब्राउज़र कैश साफ़ करें और अस्थायी रूप से अन्य एक्सटेंशन अक्षम करें। अगर समस्या जारी रहती है, तो Donbrico पर TradeDesk AI सपोर्ट पेज में विशिष्ट ब्राउज़र संस्करणों के लिए ज्ञात वर्कअराउंड हैं।
