TradeDesk AI — Preguntas Frecuentes

Primeros Pasos

¿Cómo instalo TradeDesk AI en mi navegador?

Instala TradeDesk AI directamente desde Chrome Web Store o el mercado de extensiones de tu navegador. Una vez añadida, verás el icono de TradeDesk en la barra de herramientas del navegador: haz clic para abrir el panel de configuración, donde ingresarás tu API key y configurarás tu perfil de negocio.

¿Qué necesito para empezar a usar TradeDesk AI?

Necesitas tres cosas: un navegador compatible (Chrome, Edge o Firefox), una API key de un proveedor como OpenAI, Groq o Anthropic, y los datos básicos de tu negocio. Una vez que ingreses tu API key en la configuración de la extensión, podrás empezar a generar respuestas de inmediato — sin necesidad de registrarte ni de tarjeta de crédito para el plan gratuito.

¿Necesito crear una cuenta en Donbrico para usar la extensión?

No se requiere ninguna cuenta. TradeDesk AI funciona completamente a través de la extensión de tu navegador usando tu propia API key. No hay inicio de sesión en la nube, ni contraseñas que recordar, ni base de datos de usuarios — solo instala, configura y empieza a redactar.

¿Cómo configuro mi perfil de negocio por primera vez?

Abre el panel de la extensión y ve a la sección "Perfil de Negocio". Completa el nombre de tu empresa, número de teléfono, correo electrónico, número de licencia y área de servicio. Una vez guardado, TradeDesk AI rellenará automáticamente estos datos en cada respuesta, presupuesto y estimación que generes — ahorrándote tener que escribir la misma información repetidamente.

Funciones y Uso

¿Cómo uso TradeDesk AI dentro de Gmail u Outlook?

Redacta un nuevo correo o responde a un hilo existente, luego haz clic en el icono de TradeDesk AI que aparece dentro de la ventana de correo. Selecciona un escenario (como "Solicitud de Presupuesto" o "Seguimiento"), añade tus notas rápidas y haz clic en Generar — la extensión insertará una respuesta pulida directamente en el cuerpo del mensaje.

¿Cuáles son los más de 23 escenarios integrados y cómo elijo el correcto?

Los escenarios cubren comunicaciones comunes de contratistas: estimaciones de presupuesto, seguimientos de permisos, confirmaciones de trabajos, órdenes de cambio, recordatorios de garantía y más. Cuando abras el menú de escenarios, cada opción incluye una breve descripción. Si no estás seguro, empieza con "Respuesta Rápida" — se adapta a cualquier nota que proporciones.

¿Puede TradeDesk AI generar presupuestos y estimaciones, o solo respuestas de correo?

Maneja ambas cosas. Selecciona un escenario como "Estimación Formal" o "Presupuesto de Materiales", ingresa los detalles del trabajo y los precios, y TradeDesk AI lo formateará todo en un documento profesional. El resultado funciona en cualquier formulario web, así que puedes pegarlo en tu CRM, herramienta de facturación o portal de clientes.

¿Cómo funciona la especialización por oficio para HVAC, fontanería o electricidad?

En la configuración de la extensión, selecciona tu oficio principal de la lista de 8 opciones — HVAC, fontanería, electricidad, techado, jardinería, manitas, pintura o contratación general. TradeDesk AI usa entonces terminología específica del sector para ese oficio al generar respuestas, así que un fontanero obtiene "calentador de agua" y "línea de desagüe", mientras que un electricista obtiene "panel de interruptores" y "conducto".

¿Puedo guardar mis propias plantillas y reutilizarlas después?

Sí, el plan gratuito incluye 5 espacios para plantillas guardadas. Después de generar una respuesta que te guste, haz clic en "Guardar como Plantilla" y ponle un nombre. Puedes cargar esa plantilla en sesiones futuras y regenerarla con detalles actualizados — útil para trabajos recurrentes o promociones de temporada.

Privacidad y Seguridad

¿Dónde se procesan mis datos cuando uso TradeDesk AI?

Todo el procesamiento de datos ocurre a través de la API del proveedor que elijas — TradeDesk AI no tiene servidores backend propios. La extensión envía tus notas directamente desde tu navegador al endpoint de API que configures (OpenAI, Groq, Anthropic, etc.), y la respuesta generada vuelve a tu navegador. No se almacena ni registra nada en la infraestructura de Donbrico.

¿TradeDesk AI almacena mis correos electrónicos o información de clientes?

No. TradeDesk AI lee el hilo de correo que estás viendo actualmente solo para proporcionar contexto a la generación de IA. No guarda, almacena en caché ni transmite tus correos, nombres de clientes, direcciones ni ningún otro dato personal a ningún servidor fuera de la llamada API que autorices.

¿Es seguro usar mi propia API key con esta extensión?

Sí, y es el enfoque más seguro. Tu API key se almacena localmente en el almacenamiento de la extensión de tu navegador, no en ningún servidor remoto. Cuando generas una respuesta, la clave se pasa directamente al proveedor de la API — de la misma manera que funciona cualquier aplicación que use API keys. Puedes revocar o rotar la clave en cualquier momento desde el panel de tu proveedor.

¿Qué pasa si uso TradeDesk AI en un ordenador compartido o público?

Recomendamos cerrar sesión en la extensión o eliminar tu API key antes de dejar un ordenador compartido. Como la clave se almacena localmente, cualquier persona con acceso a ese navegador podría usar tu clave para generar respuestas. Para estaciones de trabajo compartidas, considera usar una API key temporal con límites de uso.

Precios y Licencias

¿Qué incluye el plan gratuito y cuánto dura?

El plan gratuito te da 5 respuestas generadas por IA al día y 5 espacios para plantillas guardadas — y nunca caduca. Solo necesitas tu propia API key para empezar. Es ideal para contratistas que envían unos cuantos correos al día y quieren probar la herramienta antes de comprometerse.

¿Cuánto cuesta el plan premium y qué incluye?

Los detalles de precios están disponibles en el sitio web de Donbrico, en la página de TradeDesk AI. El plan premium elimina el límite diario de respuestas, añade almacenamiento ilimitado de plantillas y desbloquea acceso prioritario a nuevos escenarios y funciones. Todos los planes usan tu propia API key — no hay tarifa por mensaje de Donbrico.

¿Puedo usar una API key para varios usuarios de mi empresa?

Sí, pero consulta los términos de tu proveedor de API. Algunos proveedores (como OpenAI) permiten claves compartidas con seguimiento de uso, mientras que otros pueden requerir claves por usuario. TradeDesk AI no restringe cuántos dispositivos usan la misma clave — cada instalación es independiente y se configura localmente.

Solución de Problemas

¿Por qué no aparece TradeDesk AI en mi ventana de redacción de correo?

Primero, asegúrate de que la extensión esté habilitada en el administrador de extensiones de tu navegador. Luego, actualiza la pestaña de tu correo. Si aún no aparece, verifica que estés en una plataforma compatible (Gmail, Outlook web, Yahoo Mail). Para otros formularios web, es posible que necesites hacer clic dentro del campo de texto antes de que se active el icono de TradeDesk.

La IA generó una respuesta, pero no suena a mí — ¿cómo lo soluciono?

Actualiza tu perfil de negocio con detalles específicos sobre el tono y estilo de tu empresa. En la configuración de la extensión, puedes añadir instrucciones personalizadas como "Usa siempre un tono amigable" o "Incluye nuestra información de garantía". También puedes editar el texto generado directamente antes de enviarlo — TradeDesk AI es una herramienta de redacción, no un resultado final.

Recibo un error sobre mi API key constantemente — ¿qué debo revisar?

Los problemas comunes incluyen: API key caducada, créditos insuficientes en tu cuenta de proveedor, o copiar espacios adicionales al pegar la clave. Ve al panel de tu proveedor de API, genera una nueva clave de prueba y pégala con cuidado en la configuración de TradeDesk AI. Si el error persiste, verifica que seleccionaste el proveedor correcto (OpenAI, Groq, etc.) en el menú desplegable de la extensión.

TradeDesk AI va lento o no responde — ¿qué puedo hacer?

El rendimiento depende del tiempo de respuesta de tu proveedor de API y de tu conexión a internet. Intenta cambiar a un proveedor más rápido como Groq si estás usando uno más lento. También, limpia la caché de tu navegador y desactiva otras extensiones temporalmente para descartar conflictos. Si el problema continúa, la página de soporte de TradeDesk AI en Donbrico tiene soluciones conocidas para versiones específicas de navegadores.
