Autofill AI — 常见问题解答

入门指南

如何在 Chrome 浏览器中安装 Autofill AI？

访问 Chrome 网上应用店，搜索“Autofill AI by Donbrico”，或直接前往产品页面 donbrico.net/autofill-ai。点击“添加至 Chrome”并确认安装。无需创建账户或注册——安装后即可立即使用。

使用 Autofill AI 需要创建账户吗？

不需要。Autofill AI 无需账户即可使用。安装扩展程序，保存个人资料数据，即可开始填写表单。无需登录、无需邮箱验证，设置过程中也不会收集任何个人信息。

如何首次设置我的个人资料？

点击 Chrome 工具栏中的 Autofill AI 图标，选择“管理个人资料”。输入您的标准信息，如姓名、邮箱、电话号码和地址。保存后，此个人资料将存储在浏览器本地，并用于自动填写任何网站上的标准字段。

使用 AI 回答功能前需要配置什么？

对于开放式字段（如求职信）的 AI 生成答案，您有两种选择。默认情况下，Autofill AI 使用 Gemini Nano，该模型完全在 Chrome 内部运行。或者，您也可以在扩展设置中自行输入来自 OpenAI、Anthropic、Groq 或 OpenRouter 等提供商的 API 密钥。

功能与使用

Autofill AI 如何检测网页上的字段？

当您访问包含表单的页面时，Autofill AI 会扫描 HTML 结构，寻找常见的字段标签和输入类型，如文本框、下拉菜单和文本区域。它会将这些与您保存的个人资料中的字段进行匹配，并高亮显示检测到的字段，让您清楚哪些内容将被填写。

我可以在提交前编辑 AI 生成的答案吗？

可以。在 AI 生成的内容插入表单字段之前，Autofill AI 会显示答案供您审阅。您可以直接在字段中编辑文本，如果第一个答案不合适，也可以重新生成。未经您的批准，不会自动提交任何内容。

Autofill AI 是否适用于所有包含表单的网站？

Autofill AI 旨在适用于任何使用标准 HTML 表单元素的网站。这包括求职申请门户、医疗信息登记表、保险理赔系统和自由职业提案页面。在极少数情况下，如果网站使用自定义的非标准表单构建器，检测能力可能会受限。

如何一键使用 Autofill AI 填写表单？

导航到包含表单的页面，然后点击工具栏中的 Autofill AI 图标，或使用键盘快捷键（可在设置中配置）。扩展程序会立即用您的个人资料数据填充所有检测到的标准字段。对于开放式字段，它会生成 AI 答案，您可以在插入前进行审阅。

我可以为不同用途保存多个个人资料吗？

目前，Autofill AI 一次仅支持一个活动个人资料。您可以根据不同场景需要编辑个人资料详情，例如在个人地址和工作地址之间切换。多个个人资料支持功能正在考虑纳入未来更新。

隐私与安全

我的个人数据存储在哪里？

您的所有个人资料数据都存储在 Chrome 浏览器的本地扩展程序存储中。数据永远不会离开您的设备，不会上传到任何服务器，Donbrico 或任何第三方均无法访问。

AI 如何在不将数据发送到服务器的情况下生成答案？

默认情况下，Autofill AI 使用 Google 的 Gemini Nano 模型，这是一个小型语言模型，通过浏览器内置的 AI 功能直接在 Chrome 内部运行。处理过程无需通过互联网发送任何数据。如果您选择使用自己的 API 密钥，则数据仅发送给您指定的提供商，并遵循您自己的账户条款。

在 Autofill AI 中使用自己的 API 密钥安全吗？

安全。您的 API 密钥存储在浏览器本地，仅用于向您配置的提供商（OpenAI、Anthropic、Groq 或 OpenRouter）发送请求。扩展程序不会在其他地方记录、存储或传输您的密钥。您完全控制由哪个提供商处理您的数据。

Autofill AI 会收集任何使用分析或跟踪数据吗？

不会。Autofill AI 采用严格的无跟踪政策。没有分析脚本、没有遥测功能、也没有用户行为跟踪。扩展程序在个人资料存储和默认 AI 处理方面完全离线运行，仅在您提供密钥时才会进行可选的 API 调用。

定价与许可

Autofill AI 是免费使用的吗？

是的，Autofill AI 完全免费安装和使用。没有高级套餐、订阅费用或隐藏收费。所有功能，包括通过 Gemini Nano 生成的 AI 答案，均免费提供。

填写表单的数量有限制吗？

没有。您可以无限量填写表单，没有使用上限或速率限制。唯一的潜在限制是，如果您选择使用自己的 API 密钥，则需遵守该提供商的使用政策和定价。

Autofill AI 未来会推出付费计划吗？

目前没有推出付费计划的打算。Autofill AI 由 Donbrico 作为免费工具维护。如果未来定价发生变化，将提前充分通知现有用户。

故障排除

Autofill AI 无法检测表单上的字段。该怎么办？

首先，刷新页面并确保表单完全加载后再点击 Autofill AI 图标。某些动态表单需要用户交互后才会加载字段，因此请先尝试点击某个字段。如果检测仍然失败，则该网站可能使用了 Autofill AI 无法解析的非标准表单元素。

为什么 AI 生成的答案为空或不显示？

请确保您已在 Chrome 设置中启用 Gemini Nano，或在扩展设置中输入了有效的 API 密钥。如果使用 API 密钥，请验证您的账户是否有可用额度，以及密钥是否具有正确的权限。同时检查表单字段是否为真正的开放式文本区域，而非下拉菜单或按钮。

Chrome 更新后扩展程序停止工作。

Chrome 更新有时会影响扩展程序的权限或设置。请尝试在扩展程序菜单（chrome://extensions）中禁用并重新启用 Autofill AI。如果问题仍然存在，请从 Chrome 网上应用店卸载并重新安装扩展程序。您的个人资料数据存储在本地，重新安装后不会丢失。

如何报告错误或请求新功能？

请访问 Donbrico 网站 donbrico.net，使用联系表单提交您的反馈。请提供您遇到问题的网站详情、复现步骤以及您的 Chrome 版本。功能请求会定期审核，以用于未来更新。
