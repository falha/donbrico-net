Autofill AI — 常見問題解答

開始使用

如何在 Chrome 瀏覽器安裝 Autofill AI？

前往 Chrome 線上應用程式商店，搜尋「Autofill AI by Donbrico」，或直接造訪產品頁面 donbrico.net/autofill-ai。點擊「加到 Chrome」並確認安裝。無需建立帳戶或註冊，安裝後即可立即使用。

使用 Autofill AI 需要建立帳戶嗎？

不需要，Autofill AI 無需帳戶。安裝擴充功能後，儲存個人資料檔，就能開始填寫表單。過程中無需登入、無需電子郵件驗證，也不會收集任何個人資訊。

如何首次設定個人資料？

點擊 Chrome 工具列中的 Autofill AI 圖示，選擇「管理個人資料」。輸入姓名、電子郵件、電話號碼和地址等標準資訊。儲存後，這份資料會存放在瀏覽器本機端，並用於自動填寫任何網站的標準欄位。

使用 AI 回答功能前需要設定什麼？

針對開放式欄位（如求職信）的 AI 生成回答，您有兩種選擇。預設情況下，Autofill AI 使用 Gemini Nano，完全在 Chrome 內部運作。或者，您也可以前往擴充功能設定，輸入來自 OpenAI、Anthropic、Groq 或 OpenRouter 等供應商的 API 金鑰。

功能與使用方式

Autofill AI 如何偵測網頁上的欄位？

當您造訪含有表單的頁面時，Autofill AI 會掃描 HTML 結構，尋找常見的欄位標籤與輸入類型，例如文字框、下拉選單和文字區域。它會將這些欄位與您儲存的個人資料進行比對，並標記已偵測到的欄位，讓您清楚哪些部分會被填寫。

我可以在送出前編輯 AI 生成的回答嗎？

可以。在 AI 生成的內容插入表單欄位之前，Autofill AI 會先顯示回答供您檢閱。您可以直接在欄位中編輯文字，如果第一個答案不滿意，也可以重新生成。未經您的核准，不會自動送出任何內容。

Autofill AI 能在所有含有表單的網站上運作嗎？

Autofill AI 專為任何使用標準 HTML 表單元素的網站而設計，包括求職申請入口、醫療病歷表單、保險理賠系統和自由工作者提案頁面。在少數情況下，如果網站使用自訂的非標準表單建構工具，偵測效果可能會受到限制。

如何一鍵使用 Autofill AI 填寫表單？

前往含有表單的頁面，點擊工具列中的 Autofill AI 圖示，或使用鍵盤快捷鍵（可在設定中自訂）。擴充功能會立即用您的個人資料填入所有偵測到的標準欄位。對於開放式欄位，則會生成 AI 回答，供您在插入前進行檢閱。

我可以為不同用途儲存多個個人資料嗎？

目前 Autofill AI 一次僅支援一個作用中的個人資料。您可以根據不同情境編輯個人資料細節，例如在個人地址和工作地址之間切換。未來更新中正在考慮支援多個個人資料功能。

隱私與安全性

我的個人資料存放在哪裡？

所有個人資料都儲存在您 Chrome 瀏覽器的本機端擴充功能儲存空間中。資料絕不會離開您的裝置，不會上傳到任何伺服器，Donbrico 或任何第三方也無法存取。

AI 如何在不將資料傳送到伺服器的情況下生成回答？

預設情況下，Autofill AI 使用 Google 的 Gemini Nano 模型，這是一個小型語言模型，透過瀏覽器內建的 AI 功能直接在 Chrome 內部運作。無需透過網際網路傳送任何資料進行處理。如果您選擇使用自己的 API 金鑰，則資料只會根據您的帳戶條款傳送到您指定的供應商。

在 Autofill AI 中使用自己的 API 金鑰安全嗎？

安全。您的 API 金鑰會儲存在瀏覽器本機端，僅用於向您設定的供應商（OpenAI、Anthropic、Groq 或 OpenRouter）發出請求。擴充功能不會在別處記錄、儲存或傳輸您的金鑰。您完全掌控哪個供應商處理您的資料。

Autofill AI 會收集任何使用分析或追蹤資料嗎？

不會。Autofill AI 秉持嚴格的無追蹤政策。沒有分析腳本、沒有遙測技術、也沒有使用者行為追蹤。擴充功能在個人資料儲存與預設 AI 處理方面完全離線運作，僅在您提供金鑰時才會進行選擇性的 API 呼叫。

價格與授權

Autofill AI 是免費的嗎？

是的，Autofill AI 完全免費安裝與使用。沒有高級方案、訂閱費用或隱藏收費。所有功能（包括透過 Gemini Nano 生成的 AI 回答）均免費提供。

填寫表單的數量有限制嗎？

沒有。您可以隨意填寫任意數量的表單，沒有使用上限或速率限制。唯一的潛在限制是，如果您選擇使用自己的 API 金鑰，則需遵守該供應商的使用政策與價格規定。

Autofill AI 未來會推出付費方案嗎？

目前沒有推出付費方案的計畫。Autofill AI 由 Donbrico 作為免費工具維護。如果未來價格有所變動，將會提前充分通知現有使用者。

疑難排解

Autofill AI 沒有偵測到表單上的欄位，該怎麼辦？

首先，重新整理頁面，並確保表單已完全載入後再點擊 Autofill AI 圖示。某些動態表單會在使用者互動後才載入欄位，因此請先嘗試點擊某個欄位。如果仍無法偵測，可能是該網站使用了 Autofill AI 無法解析的非標準表單元素。

為什麼 AI 生成的回答是空的或沒有出現？

請確認您已在 Chrome 設定中啟用 Gemini Nano，或在擴充功能設定中輸入了有效的 API 金鑰。如果使用 API 金鑰，請檢查您的帳戶是否有足夠的額度，以及金鑰是否具有正確的權限。同時確認表單欄位確實是開放式的文字區域，而非下拉選單或按鈕。

Chrome 更新後擴充功能停止運作。

Chrome 更新有時會影響擴充功能的權限或設定。請嘗試在擴充功能選單（chrome://extensions）中停用後再啟用 Autofill AI。如果問題持續存在，請從 Chrome 線上應用程式商店解除安裝並重新安裝擴充功能。您的個人資料儲存在本機端，重新安裝後不會遺失。

如何回報錯誤或要求新功能？

請造訪 Donbrico 網站 donbrico.net，使用聯絡表單提交您的意見回饋。請提供您遇到問題的網站詳細資訊、重現步驟以及您的 Chrome 版本。功能請求會定期檢視，以納入未來更新。
