Autofill AI — 자주 묻는 질문

시작하기

Chrome 브라우저에 Autofill AI를 어떻게 설치하나요?

Chrome 웹 스토어에서 "Autofill AI by Donbrico"를 검색하거나, donbrico.net/autofill-ai에서 제품 페이지로 바로 이동하세요. "Chrome에 추가"를 클릭하고 설치를 확인하세요. 계정 생성이나 가입이 필요 없으며, 설치 후 바로 사용할 수 있습니다.

Autofill AI를 사용하려면 계정을 만들어야 하나요?

아니요, Autofill AI는 계정이 필요하지 않습니다. 확장 프로그램을 설치하고 프로필 데이터를 저장한 후 즉시 양식 작성을 시작할 수 있습니다. 설정 과정에서 로그인, 이메일 인증, 개인정보 수집이 전혀 없습니다.

처음으로 프로필을 설정하려면 어떻게 해야 하나요?

Chrome 도구 모음에서 Autofill AI 아이콘을 클릭하고 "프로필 관리"를 선택하세요. 이름, 이메일, 전화번호, 주소 등 기본 정보를 입력합니다. 저장되면 이 프로필은 브라우저에 로컬로 저장되며, 모든 웹사이트에서 표준 필드를 자동으로 채우는 데 사용됩니다.

AI 답변 기능을 사용하기 전에 무엇을 설정해야 하나요?

자기소개서 같은 자유 형식 필드에 AI 생성 답변을 사용하려면 두 가지 옵션이 있습니다. 기본적으로 Autofill AI는 Chrome 내에서 완전히 실행되는 Gemini Nano를 사용합니다. 또는 확장 프로그램 설정에서 API 키를 입력하여 OpenAI, Anthropic, Groq, OpenRouter 같은 제공업체의 키를 직접 사용할 수 있습니다.

기능 및 사용법

Autofill AI는 웹페이지에서 필드를 어떻게 감지하나요?

양식이 있는 페이지를 방문하면 Autofill AI가 HTML 구조를 스캔하여 텍스트 상자, 드롭다운, 텍스트 영역 같은 일반적인 필드 레이블과 입력 유형을 찾습니다. 이를 저장된 프로필의 필드와 매칭하고, 감지된 필드를 강조 표시하여 무엇이 채워질지 확인할 수 있습니다.

AI가 생성한 답변을 제출하기 전에 수정할 수 있나요?

네. AI 생성 콘텐츠가 양식 필드에 삽입되기 전에 Autofill AI가 답변을 검토할 수 있도록 표시합니다. 필드에서 텍스트를 직접 수정하거나, 첫 번째 답변이 적합하지 않으면 새 답변을 다시 생성할 수 있습니다. 승인 없이 자동으로 제출되는 내용은 없습니다.

Autofill AI는 모든 웹사이트의 양식에서 작동하나요?

Autofill AI는 표준 HTML 양식 요소를 사용하는 모든 웹사이트에서 작동하도록 설계되었습니다. 여기에는 채용 지원 포털, 의료 접수 양식, 보험 청구 시스템, 프리랜서 제안 페이지가 포함됩니다. 드물게 맞춤형 비표준 양식 빌더를 사용하는 웹사이트에서는 감지가 제한될 수 있습니다.

한 번의 클릭으로 양식을 채우려면 어떻게 해야 하나요?

양식이 있는 페이지로 이동한 후 도구 모음에서 Autofill AI 아이콘을 클릭하거나 키보드 단축키(설정에서 구성 가능)를 사용하세요. 확장 프로그램이 감지된 모든 표준 필드를 프로필 데이터로 즉시 채웁니다. 자유 형식 필드의 경우 AI 답변이 생성되며, 삽입 전에 검토할 수 있습니다.

여러 프로필을 다른 용도로 저장할 수 있나요?

현재 Autofill AI는 한 번에 하나의 활성 프로필을 지원합니다. 개인 주소와 직장 주소를 전환하는 등 필요에 따라 프로필 세부 정보를 편집할 수 있습니다. 여러 프로필 지원은 향후 업데이트에서 고려 중입니다.

개인정보 및 보안

내 개인 데이터는 어디에 저장되나요?

모든 프로필 데이터는 확장 프로그램의 로컬 저장소를 사용하여 Chrome 브라우저에 로컬로 저장됩니다. 데이터가 기기를 떠나지 않으며, 어떤 서버에도 업로드되지 않고, Donbrico나 제3자가 접근할 수 없습니다.

AI는 데이터를 서버로 보내지 않고 어떻게 답변을 생성하나요?

기본적으로 Autofill AI는 Google의 Gemini Nano 모델을 사용합니다. 이는 브라우저 내장 AI 기능을 통해 Chrome 내에서 직접 실행되는 소형 언어 모델입니다. 처리 과정에서 인터넷으로 데이터가 전송되지 않습니다. 자체 API 키를 사용하기로 선택한 경우, 데이터는 귀하의 계정 조건에 따라 지정한 제공업체로만 전송됩니다.

Autofill AI에서 내 API 키를 사용해도 안전한가요?

네. API 키는 브라우저에 로컬로 저장되며, 설정한 제공업체(OpenAI, Anthropic, Groq, OpenRouter)에 요청을 보내는 데만 사용됩니다. 확장 프로그램은 키를 기록, 저장, 전송하지 않습니다. 귀하가 데이터를 처리할 제공업체를 완전히 제어할 수 있습니다.

Autofill AI는 사용 분석이나 추적 데이터를 수집하나요?

아니요. Autofill AI는 엄격한 무추적 정책으로 제작되었습니다. 분석 스크립트, 원격 측정, 사용자 행동 추적이 전혀 없습니다. 확장 프로그램은 프로필 저장 및 기본 AI 처리를 위해 완전히 오프라인으로 작동하며, 키를 제공한 경우에만 선택적 API 호출이 이루어집니다.

가격 및 라이선스

Autofill AI는 무료인가요?

네, Autofill AI는 설치 및 사용이 완전히 무료입니다. 프리미엄 등급, 구독료, 숨은 비용이 없습니다. Gemini Nano를 통한 AI 생성 답변을 포함한 모든 기능을 비용 없이 이용할 수 있습니다.

채울 수 있는 양식 수에 제한이 있나요?

아니요. 사용량 제한이나 속도 제한 없이 원하는 만큼 양식을 채울 수 있습니다. 유일한 잠재적 제한은 자체 API 키를 사용하기로 선택한 경우로, 해당 제공업체의 사용 정책과 가격이 적용됩니다.

Autofill AI가 유료 요금제를 도입할 예정인가요?

현재 유료 요금제 도입 계획은 없습니다. Autofill AI는 Donbrico가 무료 도구로 유지 관리합니다. 향후 가격 변경이 있을 경우, 기존 사용자에게 사전에 충분히 공지할 예정입니다.

문제 해결

Autofill AI가 양식에서 필드를 감지하지 못합니다. 어떻게 해야 하나요?

먼저 페이지를 새로고침하고, Autofill AI 아이콘을 클릭하기 전에 양식이 완전히 로드되었는지 확인하세요. 일부 동적 양식은 사용자 상호작용 후에 필드를 로드하므로, 먼저 필드를 클릭해 보세요. 그래도 감지가 실패하면 웹사이트가 Autofill AI가 분석할 수 없는 비표준 양식 요소를 사용하고 있을 수 있습니다.

AI 생성 답변이 비어 있거나 나타나지 않는 이유는 무엇인가요?

Chrome 설정에서 Gemini Nano를 활성화했거나 확장 프로그램 설정에 유효한 API 키를 입력했는지 확인하세요. API 키를 사용하는 경우 계정에 사용 가능한 크레딧이 있고 키에 올바른 권한이 있는지 확인하세요. 또한 양식 필드가 드롭다운이나 버튼이 아닌 자유 형식 텍스트 영역인지 확인하세요.

Chrome 업데이트 후 확장 프로그램이 작동을 멈췄습니다.

Chrome 업데이트는 때때로 확장 프로그램 권한이나 설정에 영향을 줄 수 있습니다. 확장 프로그램 메뉴(chrome://extensions)에서 Autofill AI를 비활성화했다가 다시 활성화해 보세요. 문제가 지속되면 Chrome 웹 스토어에서 확장 프로그램을 제거하고 다시 설치하세요. 프로필 데이터는 로컬에 저장되므로 재설치해도 손실되지 않습니다.

버그를 신고하거나 새 기능을 요청하려면 어떻게 해야 하나요?

Donbrico 웹사이트(donbrico.net)를 방문하여 문의 양식으로 피드백을 제출하세요. 문제가 발생한 웹사이트, 재현 단계, Chrome 버전에 대한 세부 정보를 포함해 주세요. 기능 요청은 향후 업데이트를 위해 정기적으로 검토됩니다.
