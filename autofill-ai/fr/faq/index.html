Autofill AI — Foire aux questions

Pour commencer

Comment installer Autofill AI sur mon navigateur Chrome ?

Rendez-vous sur le Chrome Web Store et recherchez « Autofill AI by Donbrico », ou accédez directement à la page produit sur donbrico.net/autofill-ai. Cliquez sur « Ajouter à Chrome » et confirmez l'installation. Aucune création de compte ni inscription n'est nécessaire — vous pouvez l'utiliser immédiatement après l'installation.

Dois-je créer un compte pour utiliser Autofill AI ?

Non, Autofill AI ne nécessite pas de compte. Vous installez l'extension, enregistrez les données de votre profil et commencez à remplir des formulaires immédiatement. Pas de connexion, pas de vérification par e-mail et aucune information personnelle collectée lors de la configuration.

Comment configurer mon profil pour la première fois ?

Cliquez sur l'icône Autofill AI dans votre barre d'outils Chrome et sélectionnez « Gérer le profil ». Saisissez vos informations standard telles que votre nom, votre e-mail, votre numéro de téléphone et votre adresse. Une fois enregistré, ce profil est stocké localement dans votre navigateur et utilisé pour remplir automatiquement les champs standard sur n'importe quel site web.

Que dois-je configurer avant d'utiliser la fonction de réponse IA ?

Pour les réponses générées par l'IA sur les champs ouverts comme les lettres de motivation, vous avez deux options. Par défaut, Autofill AI utilise Gemini Nano, qui fonctionne entièrement dans Chrome. Vous pouvez également utiliser votre propre clé API provenant de fournisseurs comme OpenAI, Anthropic, Groq ou OpenRouter en vous rendant dans les paramètres de l'extension et en saisissant votre clé.

Fonctionnalités et utilisation

Comment Autofill AI détecte-t-il les champs sur une page web ?

Lorsque vous visitez une page contenant un formulaire, Autofill AI analyse la structure HTML pour identifier les libellés de champs courants et les types de saisie tels que les zones de texte, les listes déroulantes et les zones de texte multilignes. Il les associe aux champs de votre profil enregistré et met en évidence les champs détectés afin que vous puissiez voir ce qui sera rempli.

Puis-je modifier les réponses générées par l'IA avant de les soumettre ?

Oui. Avant que tout contenu généré par l'IA ne soit inséré dans un champ de formulaire, Autofill AI affiche la réponse pour que vous puissiez la vérifier. Vous pouvez modifier le texte directement dans le champ ou régénérer une nouvelle réponse si la première ne convient pas. Rien n'est soumis automatiquement sans votre approbation.

Autofill AI fonctionne-t-il sur tous les sites web comportant un formulaire ?

Autofill AI est conçu pour fonctionner sur tout site web utilisant des éléments de formulaire HTML standard. Cela inclut les portails de candidature, les formulaires médicaux, les systèmes de déclaration d'assurance et les pages de propositions pour freelances. Dans de rares cas où un site utilise des générateurs de formulaires personnalisés non standard, la détection peut être limitée.

Comment utiliser Autofill AI pour remplir un formulaire en un clic ?

Accédez à une page contenant un formulaire, puis cliquez sur l'icône Autofill AI dans votre barre d'outils ou utilisez le raccourci clavier (configurable dans les paramètres). L'extension remplira instantanément tous les champs standard détectés avec les données de votre profil. Pour les champs ouverts, elle générera des réponses IA que vous pourrez vérifier avant qu'elles ne soient insérées.

Puis-je enregistrer plusieurs profils pour différents cas d'utilisation ?

Actuellement, Autofill AI prend en charge un seul profil actif à la fois. Vous pouvez modifier les détails de votre profil selon les besoins, par exemple pour passer d'une adresse personnelle à une adresse professionnelle. La prise en charge de plusieurs profils est à l'étude pour de futures mises à jour.

Confidentialité et sécurité

Où sont stockées mes données personnelles ?

Toutes les données de votre profil sont stockées localement dans votre navigateur Chrome via le stockage local de l'extension. Elles ne quittent jamais votre appareil, ne sont téléchargées sur aucun serveur et ne sont accessibles ni à Donbrico ni à un tiers.

Comment l'IA génère-t-elle des réponses sans envoyer de données à un serveur ?

Par défaut, Autofill AI utilise le modèle Gemini Nano de Google, un petit modèle de langage qui fonctionne directement dans Chrome grâce aux capacités d'IA intégrées du navigateur. Aucune donnée n'est envoyée sur Internet pour être traitée. Si vous choisissez d'utiliser votre propre clé API, les données sont envoyées uniquement au fournisseur que vous spécifiez, selon les conditions de votre propre compte.

Est-il sûr d'utiliser ma propre clé API avec Autofill AI ?

Oui. Votre clé API est stockée localement dans votre navigateur et est uniquement utilisée pour effectuer des requêtes auprès du fournisseur que vous configurez (OpenAI, Anthropic, Groq ou OpenRouter). L'extension ne journalise, ne stocke ni ne transmet votre clé ailleurs. Vous contrôlez exactement quel fournisseur traite vos données.

Autofill AI collecte-t-il des statistiques d'utilisation ou des données de suivi ?

Non. Autofill AI est construit avec une politique stricte de non-suivi. Il n'y a pas de scripts d'analyse, pas de télémétrie et pas de suivi du comportement des utilisateurs. L'extension fonctionne entièrement hors ligne pour le stockage des profils et le traitement IA par défaut, avec des appels API optionnels uniquement lorsque vous fournissez une clé.

Tarification et licence

Autofill AI est-il gratuit ?

Oui, Autofill AI est totalement gratuit à installer et à utiliser. Il n'y a pas de niveaux premium, de frais d'abonnement ni de frais cachés. Toutes les fonctionnalités, y compris les réponses générées par l'IA via Gemini Nano, sont disponibles sans frais.

Y a-t-il des limitations sur le nombre de formulaires que je peux remplir ?

Non. Vous pouvez remplir autant de formulaires que vous le souhaitez, sans limite d'utilisation ni restriction de débit. La seule limitation potentielle est si vous choisissez d'utiliser votre propre clé API, auquel cas vous êtes soumis aux politiques d'utilisation et à la tarification de ce fournisseur.

Autofill AI proposera-t-il un jour un forfait payant ?

Il n'est actuellement pas prévu d'introduire un forfait payant. Autofill AI est maintenu comme un outil gratuit par Donbrico. Si des changements de tarification surviennent à l'avenir, les utilisateurs existants en seront informés bien à l'avance.

Dépannage

Autofill AI ne détecte pas les champs d'un formulaire. Que dois-je faire ?

Tout d'abord, actualisez la page et assurez-vous que le formulaire est complètement chargé avant de cliquer sur l'icône Autofill AI. Certains formulaires dynamiques chargent les champs après une interaction de l'utilisateur, essayez donc de cliquer d'abord dans un champ. Si la détection échoue toujours, il est possible que le site web utilise des éléments de formulaire non standard qu'Autofill AI ne peut pas analyser.

Pourquoi la réponse générée par l'IA est-elle vide ou n'apparaît-elle pas ?

Assurez-vous d'avoir activé Gemini Nano dans les paramètres de votre Chrome ou d'avoir saisi une clé API valide dans les paramètres de l'extension. Si vous utilisez une clé API, vérifiez que votre compte dispose de crédits disponibles et que la clé dispose des autorisations correctes. Vérifiez également que le champ du formulaire est bien une zone de texte ouverte et non une liste déroulante ou un bouton.

L'extension a cessé de fonctionner après une mise à jour de Chrome.

Les mises à jour de Chrome peuvent parfois affecter les autorisations ou les paramètres des extensions. Essayez de désactiver et de réactiver Autofill AI dans votre menu d'extensions (chrome://extensions). Si le problème persiste, désinstallez et réinstallez l'extension depuis le Chrome Web Store. Les données de votre profil sont stockées localement et ne seront pas perdues lors d'une réinstallation.

Comment signaler un bug ou demander une nouvelle fonctionnalité ?

Rendez-vous sur le site web de Donbrico à l'adresse donbrico.net et utilisez le formulaire de contact pour soumettre vos commentaires. Veuillez inclure des détails sur le site web où vous avez rencontré le problème, les étapes pour le reproduire et votre version de Chrome. Les demandes de fonctionnalités sont examinées régulièrement pour les futures mises à jour.
