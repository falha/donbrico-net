Autofill AI — Frequently Asked Questions

Getting Started

How do I install Autofill AI on my Chrome browser?

Visit the Chrome Web Store and search for "Autofill AI by Donbrico," or go directly to the product page at donbrico.net/autofill-ai. Click "Add to Chrome" and confirm the installation. No account creation or sign-up is required—you can start using it immediately after installation.

Do I need to create an account to use Autofill AI?

No, Autofill AI does not require an account. You install the extension, save your profile data, and begin filling forms right away. There is no login, no email verification, and no personal information collected during setup.

How do I set up my profile for the first time?

Click the Autofill AI icon in your Chrome toolbar and select "Manage Profile." Enter your standard information such as name, email, phone number, and address. Once saved, this profile is stored locally in your browser and used to auto-fill standard fields across any website.

What do I need to configure before using the AI answer feature?

For AI-generated answers on open-ended fields like cover letters, you have two options. By default, Autofill AI uses Gemini Nano, which runs entirely inside Chrome. Alternatively, you can bring your own API key from providers like OpenAI, Anthropic, Groq, or OpenRouter by visiting the extension settings and entering your key.

Features & Usage

How does Autofill AI detect fields on a webpage?

When you visit a page with a form, Autofill AI scans the HTML structure for common field labels and input types such as text boxes, dropdowns, and textareas. It matches these to the fields in your saved profile and highlights detected fields so you can see what will be filled.

Can I edit the AI-generated answers before submitting?

Yes. Before any AI-generated content is inserted into a form field, Autofill AI displays the answer for your review. You can edit the text directly in the field or regenerate a new answer if the first one isn't suitable. Nothing is submitted automatically without your approval.

Does Autofill AI work on every website with a form?

Autofill AI is designed to work on any website that uses standard HTML form elements. This includes job application portals, medical intake forms, insurance claims systems, and freelance proposal pages. In rare cases where a website uses custom, non-standard form builders, detection may be limited.

How do I use Autofill AI to fill a form with one click?

Navigate to a page with a form, then click the Autofill AI icon in your toolbar or use the keyboard shortcut (configurable in settings). The extension will instantly populate all detected standard fields with your profile data. For open-ended fields, it will generate AI answers which you can review before they are inserted.

Can I save multiple profiles for different use cases?

Currently, Autofill AI supports one active profile at a time. You can edit your profile details as needed for different scenarios, such as switching between a personal and work address. Multiple profile support is under consideration for future updates.

Privacy & Security

Where is my personal data stored?

All your profile data is stored locally in your Chrome browser using the extension's local storage. It never leaves your device, is not uploaded to any server, and is not accessible to Donbrico or any third party.

How does the AI generate answers without sending data to a server?

By default, Autofill AI uses Google's Gemini Nano model, which is a small language model that runs directly inside Chrome via the browser's built-in AI capabilities. No data is sent over the internet for processing. If you choose to use your own API key, data is sent only to the provider you specify under your own account terms.

Is it safe to use my own API key with Autofill AI?

Yes. Your API key is stored locally in your browser and is only used to make requests to the provider you configure (OpenAI, Anthropic, Groq, or OpenRouter). The extension does not log, store, or transmit your key anywhere else. You control exactly which provider processes your data.

Does Autofill AI collect any usage analytics or tracking data?

No. Autofill AI is built with a strict no-tracking policy. There are no analytics scripts, no telemetry, and no user behavior tracking. The extension functions entirely offline for profile storage and default AI processing, with optional API calls only when you provide a key.

Pricing & Licensing

Is Autofill AI free to use?

Yes, Autofill AI is completely free to install and use. There are no premium tiers, subscription fees, or hidden charges. All features, including AI-generated answers via Gemini Nano, are available at no cost.

Are there any limitations on how many forms I can fill?

No. You can fill as many forms as you like without any usage caps or rate limits. The only potential limitation is if you choose to use your own API key, in which case you are subject to that provider's usage policies and pricing.

Will Autofill AI ever introduce a paid plan?

There are currently no plans to introduce a paid plan. Autofill AI is maintained as a free tool by Donbrico. If changes to pricing occur in the future, existing users will be notified well in advance.

Troubleshooting

Autofill AI isn't detecting fields on a form. What should I do?

First, refresh the page and ensure the form is fully loaded before clicking the Autofill AI icon. Some dynamic forms load fields after user interaction, so try clicking into a field first. If detection still fails, the website may be using non-standard form elements that Autofill AI cannot parse.

Why is the AI-generated answer empty or not appearing?

Ensure you have either enabled Gemini Nano in your Chrome settings or entered a valid API key in the extension settings. If using an API key, verify that your account has available credits and that the key has the correct permissions. Also check that the form field is actually an open-ended textarea, not a dropdown or button.

The extension stopped working after a Chrome update.

Chrome updates can sometimes affect extension permissions or settings. Try disabling and re-enabling Autofill AI in your extensions menu (chrome://extensions). If the issue persists, uninstall and reinstall the extension from the Chrome Web Store. Your profile data is stored locally and will not be lost if you reinstall.

How do I report a bug or request a new feature?

Visit the Donbrico website at donbrico.net and use the contact form to submit your feedback. Please include details about the website where you encountered the issue, steps to reproduce it, and your Chrome version. Feature requests are reviewed regularly for future updates.
